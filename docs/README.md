## 📝 文档维护说明

### 文档更新原则

1. **项目核心文档（01-08）**：重大变更需团队讨论，保持编号顺序
2. **技术参考文档**：技术更新时及时同步
3. **业务参考文档**：业务变化时更新

### 添加新文档

请根据文档类型放入对应文件夹：
- 项目定位、目标、架构相关 → \`项目核心文档/\`
- 技术实现、开发指南相关 → \`技术参考文档/\`
- 业务逻辑、领域知识相关 → \`业务参考文档/\`

### 文档命名规范

- 项目核心文档：使用 \`01-\`, \`02-\` 等编号前缀
- 其他文档：使用清晰的描述性名称
- 使用中文命名，易于理解
