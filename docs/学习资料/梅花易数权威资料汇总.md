## 📚 核心理论

### 1. 梅花易数简介

梅花易数相传为宋代易学家**邵雍（1011-1077）**所著，是一部以易学中的数学为基础，结合易学中的"象学"进行占卜的书。

**核心原理**:
- 依先天八卦数理：乾一，兑二，离三，震四，巽五，坎六，艮七，坤八
- 精髓在于**体用论**（体卦与用卦的关系）

## 🎲 起卦方法

### 方法一：时间起卦法（最常用）

**步骤**:
1. **求上卦**: 以农历之年月日总和除以8，以余数为卦数
2. **求下卦**: 以年月日时总和除以8，以余数为卦数
3. **求动爻**: 以年月日时总和除以6，以余数为动爻位置

**公式**:
```
上卦 = (年 + 月 + 日) % 8
下卦 = (年 + 月 + 日 + 时) % 8
动爻 = (年 + 月 + 日 + 时) % 6
```

**注意**:
- 若余数为0，则视为8（对于八卦）或6（对于动爻）
- 时辰采用地支序号：子1、丑2、寅3...亥12

### 方法二：数字起卦法

当有人求测某事时，让来人随意说出两个数：
- 第一个数 → 上卦
- 第二个数 → 下卦
- 两数之和 → 动爻（两数之和 % 6）

### 方法三：字占起卦法

根据汉字的笔画数或结构起卦。

### 方法四：其他起卦法

凡为人占：
- 听语声起卦
- 观其人品
- 取诸身
- 取诸物
- 因其服色、触其外物

## 📖 卦象体系

### 1. 本卦（主卦）

起卦后得到的原始卦象，由上卦和下卦组成。

### 2. 互卦

**计算方法**:
- **下互卦**: 本卦的第2、3、4爻组成
- **上互卦**: 本卦的第3、4、5爻组成

**作用**: 互卦反映事物发展的中间过程或潜在趋势

### 3. 变卦

**计算方法**:
- 将动爻变化（阳变阴，阴变阳）
- 其他爻保持不变

**作用**: 变卦反映事物发展的最终结果

### 4. 体卦与用卦

**关键规则**:
- **体卦**: 没有动爻的三画卦
- **用卦**: 有动爻的三画卦

**意义**:
- 体卦 → 自己、主体
- 用卦 → 他人、所占之事

## 🔥 五行生克关系

### 八卦五行对应

| 八卦 | 五行 | 特性 |
|------|------|------|
| 乾、兑 | 金 | 刚健、肃杀 |
| 震、巽 | 木 | 生长、曲直 |
| 坎 | 水 | 润下、寒凉 |
| 离 | 火 | 炎上、光明 |
| 艮、坤 | 土 | 厚重、中和 |

### 生克关系

**相生**: 木→火→土→金→水→木（循环）

**相克**: 木克土、土克水、水克火、火克金、金克木

## 📊 断卦方法

### 核心原则

**体用生克之辩**:
1. **用卦生体卦** → 大吉
2. **体卦克用卦** → 小吉
3. **体卦生用卦** → 小凶（泄气）
4. **用卦克体卦** → 大凶

### 断卦步骤

1. **确定本卦**: 得到上卦、下卦、动爻
2. **区分体用**:
   - 动爻所在卦 = 用卦
   - 另一卦 = 体卦
3. **计算互卦**: 2-3-4爻（下互），3-4-5爻（上互）
4. **计算变卦**: 动爻变化
5. **分析五行关系**:
   - 本卦：体用关系
   - 互卦：中间过程（互卦也属用卦）
   - 变卦：最终结果（变卦也属用卦）
6. **综合判断**: 结合卦象含义、五行生克、时间因素

### 判断吉凶要点

**吉的情况**:
- 用卦生体卦
- 体卦与用卦比和（同五行）
- 卦象含义吉祥

**凶的情况**:
- 用卦克体卦
- 体卦生用卦（泄气）
- 卦象含义凶险

## ⚠️ 重要注意事项

### 1. 起卦的时间基准

- 必须使用**农历**（阴历）年月日
- 时辰使用**地支**（子丑寅卯...）

### 2. 余数处理

- 除以8或6后，**若余数为0**，则取为8或6（不能为0）

### 3. 体用判定

- **必须有动爻**才能区分体用
- 如无动爻，则需采用其他判断方法

### 4. 占卜态度

引用原文：
> "占卜的关键就在于圆融变通，必须义理象数结合，不能只讲数的推算而不讲事物之常理。"
