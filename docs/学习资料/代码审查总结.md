### P0-1: 梅花易数变卦计算错误 🔴🔴🔴

**严重程度**: 🔴 高 - 导致所有变卦结果错误

**位置**: `src/meihua/qigua.ts` 第 65-90 行

#### 当前实现（错误）

```typescript
// ❌ 错误的实现
function getChangeGua(upperGua: BaGua, lowerGua: BaGua, changingLine: number) {
  const guaToIndex: Record<BaGua, number> = {
    '乾': 1, '兑': 2, '离': 3, '震': 4,
    '巽': 5, '坎': 6, '艮': 7, '坤': 8
  };

  let newUpperIndex = guaToIndex[upperGua];
  let newLowerIndex = guaToIndex[lowerGua];

  if (changingLine <= 3) {
    // ❌ 问题：简单地将八卦索引+1
    newLowerIndex = (newLowerIndex % 8) + 1;
  } else {
    // ❌ 问题：简单地将八卦索引+1
    newUpperIndex = (newUpperIndex % 8) + 1;
  }

  return {
    upperGua: BA_GUA_BY_INDEX[newUpperIndex],
    lowerGua: BA_GUA_BY_INDEX[newLowerIndex]
  };
}
```

#### 问题分析

1. ❌ 只是将八卦索引 +1，这不符合易经原理
2. ❌ 没有真正改变爻的阴阳属性
3. ❌ 导致变卦结果完全错误

#### 正确实现（应该修复为）

```typescript
// ✅ 正确的实现
// 1. 定义八卦的二进制表示（阳=1，阴=0，从下往上）
const GUA_TO_BINARY: Record<BaGua, string> = {
  '乾': '111',  // ☰ 三阳爻
  '兑': '110',  // ☱ 缺上
  '离': '101',  // ☲ 缺中
  '震': '100',  // ☳ 缺下上
  '巽': '011',  // ☴ 缺下
  '坎': '010',  // ☵ 缺中上
  '艮': '001',  // ☶ 缺上中
  '坤': '000'   // ☷ 三阴爻
};

function getChangeGua(upperGua: BaGua, lowerGua: BaGua, changingLine: number) {
  // 1. 组合成六爻
  const lowerBinary = GUA_TO_BINARY[lowerGua];  // 1-3爻
  const upperBinary = GUA_TO_BINARY[upperGua];  // 4-6爻
  const sixLines = lowerBinary + upperBinary;    // 组合成六位二进制

  // 2. 翻转动爻（阳变阴，阴变阳）
  const lines = sixLines.split('');
  const index = changingLine - 1;
  lines[index] = lines[index] === '1' ? '0' : '1';  // ✅ 翻转动爻
  const newSixLines = lines.join('');

  // 3. 拆分回上下卦
  const newLowerBinary = newSixLines.substring(0, 3);
  const newUpperBinary = newSixLines.substring(3, 6);

  // 4. 转回八卦
  const binaryToGua = Object.fromEntries(
    Object.entries(GUA_TO_BINARY).map(([k, v]) => [v, k as BaGua])
  );

  return {
    lowerGua: binaryToGua[newLowerBinary],
    upperGua: binaryToGua[newUpperBinary]
  };
}
```

#### 影响范围

- 所有梅花易数占卜的变卦结果都是错误的
- 影响断卦准确性
- 必须立即修复
