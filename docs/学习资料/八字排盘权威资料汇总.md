## 📚 八字命理学基础

### 什么是八字

八字命理学（Four Pillars of Destiny）是中国传统命理学的主要分支之一，又称**四柱命理学**或**子平术**。

**核心概念**:
- 根据一个人的**出生年、月、日、时**
- 转化为天干地支的组合
- 共四柱（年柱、月柱、日柱、时柱）
- 每柱两个字（一个天干 + 一个地支）
- 总共八个字，故称"八字"

## 📅 四柱排盘算法

### 1. 年柱计算

**原则**: 以**立春**节气为界，不是农历正月初一！

**重要规则**:
> "命理换年的标准是'立春'节气，不是公历元旦，也不是农历正月初一。"
> —— 命理铁一般的标准

**计算方法**:
- 公历日期 → 查万年历 → 得到农历日期
- 判断是否已过立春节气
- 确定干支年份（六十甲子循环）

**资料来源**: [神机阁 - 真太阳时？早晚子时？平气定气？](https://www.shenjige.cn/details/RD_IfLAgza.html)

### 2. 月柱计算

**原则**: 以**节气**为界，不是农历月份！

**十二月节气对照**:
| 农历月 | 节气 | 天干起法 |
|--------|------|----------|
| 正月 | 立春 - 惊蛰 | 寅月 |
| 二月 | 惊蛰 - 清明 | 卯月 |
| 三月 | 清明 - 立夏 | 辰月 |
| 四月 | 立夏 - 芒种 | 巳月 |
| 五月 | 芒种 - 小暑 | 午月 |
| 六月 | 小暑 - 立秋 | 未月 |
| 七月 | 立秋 - 白露 | 申月 |
| 八月 | 白露 - 寒露 | 酉月 |
| 九月 | 寒露 - 立冬 | 戌月 |
| 十月 | 立冬 - 大雪 | 亥月 |
| 十一月 | 大雪 - 小寒 | 子月 |
| 十二月 | 小寒 - 立春 | 丑月 |

**月干起法** （五虎遁月诀）:
```
甲己之年丙作首（甲年、己年正月起丙寅）
乙庚之岁戊为头（乙年、庚年正月起戊寅）
丙辛必定寻庚起（丙年、辛年正月起庚寅）
丁壬壬位顺行流（丁年、壬年正月起壬寅）
更有戊癸何方觅（戊年、癸年正月起甲寅）
甲寅之上好追求
```

### 3. 日柱计算

**最复杂**: 需要使用**万年历**或**算法**计算

**关键点**:
- 日柱是八字的**核心**（日主/命主）
- 干支组合共60种（六十甲子）
- 需要精确到公历日期

**算法**: 通常使用公历转农历算法，然后查询日干支

## 🌞 真太阳时计算

### 为什么需要真太阳时

古代中国各地使用当地时间，以当地太阳角度确定时辰。现代使用统一的北京时间，但实际太阳位置因经度不同而有差异。

**计算公式**:
```
真太阳时 = 北京时间 + (当地经度 - 120°) × 4 分钟
```

**说明**:
- 120° = 东经120°（北京时间基准线）
- 每度经度差 = 4分钟时间差
- 东经大于120°则加，小于120°则减

**示例**:
- 上海（东经121°）: 加 4 分钟
- 成都（东经104°）: 减 64 分钟
- 乌鲁木齐（东经87°）: 减 132 分钟

**争议**:
现代八字排盘是否使用真太阳时存在争议，不同流派有不同看法。

### 纳音计算算法

**方法一：天干地支序号相加法**
```
纳音序号 = (天干序号 + 地支序号) % 5
若结果为0，则取5
```

**五行序号**: 木=1, 金=2, 水=3, 火=4, 土=5

**示例**:
- 甲子：甲(1) + 子(1) = 2 → 金
- 乙丑：乙(2) + 丑(2) = 4 → 火（但实际纳音也是金，因为配对）

**注意**: 纳音是**两个干支配对**的，所以实际应用时需要查表

## 👥 十神系统

### 十神定义

以**日干**为中心，与其他干支的关系确定十神：

**生我者**: 正印、偏印
**我生者**: 食神、伤官
**克我者**: 正官、七杀（偏官）
**我克者**: 正财、偏财
**同我者**: 比肩、劫财

### 判定规则

**阴阳同性**为"偏"，**异性**为"正"：

| 关系 | 同性 | 异性 |
|------|------|------|
| 生我 | 偏印（枭神） | 正印 |
| 我生 | 食神 | 伤官 |
| 克我 | 七杀（偏官） | 正官 |
| 我克 | 偏财 | 正财 |
| 同我 | 劫财 | 比肩 |

**示例**（日干为甲木）:
- 壬水生甲木（阳生阳）→ 偏印
- 癸水生甲木（阴生阳）→ 正印
- 庚金克甲木（阳克阳）→ 七杀
- 辛金克甲木（阴克阳）→ 正官

## 🔄 大运与流年

### 大运计算

**起运岁数公式**:
```
起运岁数 = (出生到下一个节气的天数) ÷ 3
```

**换算**: 3天 = 1年，1天 = 4个月，1时辰 = 10天

**大运排列规则**:
- **阳年男命、阴年女命**: 顺排（从月柱天干顺数）
- **阴年男命、阳年女命**: 逆排（从月柱天干逆数）

**阳年**: 甲丙戊庚壬年
**阴年**: 乙丁己辛癸年

**大运周期**: 每步大运10年

**示例**:
- 阳年男命，月柱丙寅，大运顺排：丁卯、戊辰、己巳、庚午...
- 阴年男命，月柱丙寅，大运逆排：乙丑、甲子、癸亥、壬戌...

### 流年计算

流年就是每一年的干支，按照六十甲子循环顺序排列。

## ⚖️ 五行生克制化

### 基本生克

**相生**: 木→火→土→金→水→木
**相克**: 木克土、土克水、水克火、火克金、金克木

### 特殊情况

**反克**: 当被克的一方过旺时，会出现"反克"
- 例：金旺克木，但木极旺时可以"反克"金

**泄**: 生也是一种"泄"
- 例：木生火，火过旺则"泄木"之气

## 📊 八字分析要点

### 1. 日主强弱

判断日主在四柱中的强弱，是分析八字的基础。

**判断因素**:
- 月令是否得时
- 地支是否得地
- 干支是否得助

### 2. 用神喜忌

**用神**: 对日主有利的五行
**忌神**: 对日主不利的五行

**基本原则**:
- 身弱者：喜生扶（印、比）
- 身旺者：喜克泄耗（官杀、食伤、财）

### 3. 格局判断

根据八字结构，判断命局格局（如正官格、食神格等）

## ⚠️ 重要技术细节

### 1. 节气精确时间

**必须使用精确的节气时间**，不是简单的日期：
- 立春可能在2月3日、4日或5日
- 具体到时辰，甚至分秒

### 2. 早晚子时问题

23:00-24:00 是"早子时"（属前一天）
00:00-01:00 是"晚子时"（属当天）

**争议**: 不同流派处理方式不同

### 3. 闰月处理

遇到闰月时，月柱以节气为准，不受闰月影响。

### 4. 平气与定气

**平气法**: 将一年平均分为24节气
**定气法**: 按照太阳黄经度数划分

现代多用定气法。

## 📝 算法实现要点总结

### 必须实现的核心功能

1. **公历转农历** - 需要万年历数据
2. **节气计算** - 精确到时分秒
3. **年柱判断** - 立春为界
4. **月柱判断** - 节气为界 + 五虎遁
5. **日柱计算** - 六十甲子循环算法
6. **时柱计算** - 真太阳时 + 五鼠遁
7. **纳音计算** - 查表或算法
8. **十神计算** - 日干与其他干支关系
9. **大运计算** - 起运岁数 + 顺逆排列
10. **流年排列** - 六十甲子循环

### 数据依赖

- 万年历数据（农历对照表）
- 节气精确时间表
- 六十甲子纳音表
- 地支藏干表
