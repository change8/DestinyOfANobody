## 问题 1：变卦计算算法错误 ✅

### 问题描述

**原始错误代码** (第 65-90 行):
```typescript
// ❌ 错误：只是将八卦索引 +1
function getChangeGua(upperGua: BaGua, lowerGua: BaGua, changingLine: number) {
  if (changingLine <= 3) {
    newLowerIndex = (newLowerIndex % 8) + 1;  // 只是简单加1
  } else {
    newUpperIndex = (newUpperIndex % 8) + 1;  // 没有真正翻转爻
  }
}
```

**问题分析**:
- 代码只是简单地将八卦索引加 1
- 没有真正翻转动爻的阴阳属性
- 违背了易经变卦的基本原理：阳爻变阴爻，阴爻变阳爻

### 修复方案

**新的正确实现** (第 62-137 行):

1. **定义八卦二进制表示**:
```typescript
const GUA_TO_BINARY: Record<BaGua, string> = {
  '乾': '111',  // ☰ 三阳爻
  '兑': '011',  // ☱ 上阴下二阳
  '离': '101',  // ☲ 中阴上下阳
  '震': '001',  // ☳ 上二阴下阳
  '巽': '110',  // ☴ 下阴上二阳
  '坎': '010',  // ☵ 上下阴中阳
  '艮': '100',  // ☶ 下二阴上阳
  '坤': '000'   // ☷ 三阴爻
};
```

2. **正确的变卦算法**:
```typescript
function getChangeGua(upperGua: BaGua, lowerGua: BaGua, changingLine: number) {
  // 1. 获取二进制表示
  const lowerBinary = GUA_TO_BINARY[lowerGua];
  const upperBinary = GUA_TO_BINARY[upperGua];

  // 2. 组合成六爻（从下往上）
  const sixLines = lowerBinary + upperBinary;

  // 3. 翻转动爻（阳变阴，阴变阳）
  const lines = sixLines.split('');
  lines[changingLine - 1] = lines[changingLine - 1] === '1' ? '0' : '1';

  // 4. 拆分回上下卦并转回八卦
  const newLowerBinary = lines.slice(0, 3).join('');
  const newUpperBinary = lines.slice(3, 6).join('');

  return {
    lowerGua: BINARY_TO_GUA[newLowerBinary],
    upperGua: BINARY_TO_GUA[newUpperBinary]
  };
}
```

## 问题 2：时间起卦使用公历 ✅

### 问题描述

**原始错误代码** (第 163-205 行):
```typescript
// ❌ 错误：使用公历年月日
export function qiguaByTime(date: Date = new Date()): GuaResult {
  const year = date.getFullYear();  // 公历 2026
  const month = date.getMonth() + 1;  // 公历月份
  const day = date.getDate();  // 公历日期

  // 使用公历数字计算...
  const upperNumber = year + month + day;
}
```

**问题分析**:
- 使用了公历（Gregorian calendar）而非农历（Lunar calendar）
- 根据梅花易数权威资料，时间起卦**必须使用农历年月日**
- 导致所有时间起卦的结果都不准确

**权威依据**:
> "以农历之年月日总和除以八，以余数为卦数求上卦"
> "以年月日时总和除以八，以余数为卦数求下卦"
>
> 来源：
> - [梅花易数起卦方式](https://www.huangli.com/wenhua/15297.html)
> - [梅花易数在线排盘](https://m.zhouyi.cc/zhouyi/meihua/)
> - [梅花易数从入门到精通](https://zhuanlan.zhihu.com/p/20227949946)

### 修复方案

**新的正确实现** (第 207-273 行):

```typescript
import { solarToLunar } from '../utils/lunar-converter';  // 导入农历转换

export function qiguaByTime(date: Date = new Date()): GuaResult {
  // 1. ✅ 转换为农历日期

  // 3. ✅ 按照正确公式计算
  const upperNumber = year + month + day;
  const lowerNumber = year + month + day + shiChen;
  const totalNumber = year + month + day + shiChen;

  // ...后续计算
}
```

## 问题 3：字占起卦逻辑问题 ✅

### 问题描述

**原始错误代码** (第 134-157 行):
```typescript
// ❌ 问题：单字时上下卦使用相同笔画数
export function qiguaByChar(char: string, strokeCount?: number): GuaResult {
  const strokes = strokeCount || getAccurateStrokeCount(char);

  // 上下卦都用相同的笔画数
  const upperNumber = strokes;
  const lowerNumber = strokes;  // ← 问题：永远相同
  const totalNumber = strokes * 2;
}
```

**问题分析**:
- 单字时上卦和下卦使用相同的笔画数
- 导致永远得到相同的上下卦（如 7 画 → 艮上艮下 = 艮为山）
- 不符合传统梅花易数的字占方法

**传统方法** (根据权威资料):

1. **单字起卦**: 将字拆分为两部分，分别计算笔画
   - 例如："明" = "日"(4画) + "月"(4画)
   - 或结合时辰：笔画数为上卦，笔画数+时辰为下卦

2. **双字起卦**: 第一字笔画为上卦，第二字笔画为下卦
   - 例如："云哲" = "云"(4画) + "哲"(10画)
   - 上卦：4 → 震卦，下卦：10 % 8 = 2 → 兑卦

**权威来源**:
- [梅花易数起卦方式有哪些](https://www.huangli.com/wenhua/15297.html)
- [梅花易数起卦方法集锦](https://k.sina.cn/article_2561051644_98a68bfc034001as1.html)
- [梅花易数起卦解卦详细步骤](http://www.360doc.com/content/25/0718/08/5473201_1157590272.shtml)

### 修复方案

**新增函数** `qiguaByChars` (推荐使用):

```typescript
export function qiguaByChars(chars: string, strokeCounts?: number[]): GuaResult {
  const charArray = Array.from(chars);
  const strokes = strokeCounts || charArray.map(c => getAccurateStrokeCount(c));

  let upperNumber: number;
  let lowerNumber: number;
  let totalNumber: number;

  if (charArray.length === 1) {
    // ✅ 单字：结合时辰
    const singleStroke = strokes[0];
    const now = new Date();
    const shiChen = Math.floor((now.getHours() + 1) / 2) % 12 || 12;

    upperNumber = singleStroke;
    lowerNumber = singleStroke + shiChen;  // 加入时辰变化
    totalNumber = singleStroke + shiChen;
  } else {
    // ✅ 多字：第一字为上卦，第二字为下卦
    upperNumber = strokes[0];
    lowerNumber = strokes[1];
    totalNumber = strokes.reduce((sum, s) => sum + s, 0);
  }

  // ...后续计算
}
```

**保留兼容** `qiguaByChar` (向后兼容):
```typescript
export function qiguaByChar(char: string, strokeCount?: number): GuaResult {
  // 调用新函数，保持向后兼容
  return qiguaByChars(char, strokeCount ? [strokeCount] : undefined);
}
```

### 使用示例

**示例 1**: 单字起卦
