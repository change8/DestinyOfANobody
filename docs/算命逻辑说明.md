# 算命逻辑说明文档

> 本文档详细说明八字排盘、易经占卜的核心算法和逻辑实现

## 1. 八字排盘逻辑

### 1.1 基础概念

**四柱八字：** 由出生年、月、日、时的天干地支组成，共八个字
- 年柱（年干 + 年支）
- 月柱（月干 + 月支）
- 日柱（日干 + 日支）
- 时柱（时干 + 时支）

**天干：** 甲、乙、丙、丁、戊、己、庚、辛、壬、癸（10个）
**地支：** 子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥（12个）

### 1.2 年柱计算

#### 1.2.1 基础算法

**公式：**
```
天干序号 = (公历年 - 3) % 10
地支序号 = (公历年 - 3) % 12
```

**示例（1990年）：**
```javascript
天干序号 = (1990 - 3) % 10 = 1987 % 10 = 7 → 庚（第7个天干）
地支序号 = (1990 - 3) % 12 = 1987 % 12 = 7 → 午（第7个地支）
结果：1990年 = 庚午年
```

#### 1.2.2 立春判断

**重要：** 年柱以**立春**为分界点，不是1月1日！

**规则：**
- 如果生日在当年立春之前，年柱使用上一年的干支
- 如果生日在立春之后，年柱使用当年的干支

**示例：**
```
1990年立春时间：1990年2月4日10:14

情况1：1990年1月15日出生 → 年柱为 己巳（1989年）
情况2：1990年3月15日出生 → 年柱为 庚午（1990年）
```

**代码实现思路：**
```typescript
function calculateYearPillar(birthDate: Date): Pillar {
  const year = birthDate.getFullYear();
  const lichun = getLichunDate(year);  // 获取当年立春时间

  // 如果生日在立春之前，使用上一年
  const actualYear = birthDate < lichun ? year - 1 : year;

  const ganIndex = (actualYear - 3) % 10;
  const zhiIndex = (actualYear - 3) % 12;

  return {
    gan: TIANGAN[ganIndex],
    zhi: DIZHI[zhiIndex]
  };
}
```

| 三月 | 清明 ~ 立夏 | 辰 | 一般在4月 |
| 四月 | 立夏 ~ 芒种 | 巳 | 一般在5月 |
| 五月 | 芒种 ~ 小暑 | 午 | 一般在6月 |
| 六月 | 小暑 ~ 立秋 | 未 | 一般在7月 |
| 七月 | 立秋 ~ 白露 | 申 | 一般在8月 |
| 八月 | 白露 ~ 寒露 | 酉 | 一般在9月 |

#### 1.3.2 天干计算（五虎遁年起月诀）

**口诀：**
```
甲己之年丙作首，乙庚之岁戊为头，
丙辛必定寻庚起，丁壬壬位顺行流，
若问戊癸何方发，甲寅之上好追求。
```

**含义：**
- 年干为甲或己，正月起丙寅
- 年干为乙或庚，正月起戊寅
- 年干为丙或辛，正月起庚寅
- 年干为丁或壬，正月起壬寅
- 年干为戊或癸，正月起甲寅

**计算公式：**
```javascript
const monthGanStart = {
  '甲': 2, '己': 2,  // 丙（索引2）
  '乙': 4, '庚': 4,  // 戊（索引4）
  '丙': 6, '辛': 6,  // 庚（索引6）
  '丁': 8, '壬': 8,  // 壬（索引8）
  '戊': 0, '癸': 0   // 甲（索引0）
};

function calculateMonthGan(yearGan: string, monthZhiIndex: number): string {
  const startIndex = monthGanStart[yearGan];
  // 正月寅月为0，依次类推
  const ganIndex = (startIndex + monthZhiIndex) % 10;
  return TIANGAN[ganIndex];
}
```

### 1.4 日柱计算

#### 1.4.1 蔡勒公式（Zeller's Formula）

日柱计算相对复杂，通常使用**蔡勒公式**：

**公式：**
```
W = ([C/4] - 2C + y + [y/4] + [13*(M+1)/5] + d - 1) mod 7
```

其中：
- C = 世纪 - 1（如1990年，C = 19）
- y = 年份后两位（如1990年，y = 90）
- M = 月份（3月为1，4月为2，...，12月为10，1月为11，2月为12）
- d = 日期

**然后转换为六十甲子：**

```javascript
function calculateDayPillar(date: Date): Pillar {
  // 已知参考点：1900年1月1日为 甲戌日
  const baseDate = new Date('1900-01-01');
  const baseDayIndex = 10;  // 甲戌在六十甲子中的索引

  // 计算距离参考点的天数
  const daysDiff = Math.floor((date.getTime() - baseDate.getTime()) / (24 * 60 * 60 * 1000));

  // 计算六十甲子索引
  const dayIndex = (baseDayIndex + daysDiff) % 60;

  return SIXTY_JIAZI[dayIndex];
}
```

| 子时 | 23:00-01:00 | 子 |
| 丑时 | 01:00-03:00 | 丑 |
| 寅时 | 03:00-05:00 | 寅 |
| 卯时 | 05:00-07:00 | 卯 |
| 辰时 | 07:00-09:00 | 辰 |

| 午时 | 11:00-13:00 | 午 |
| 未时 | 13:00-15:00 | 未 |
| 申时 | 15:00-17:00 | 申 |
| 酉时 | 17:00-19:00 | 酉 |
| 戌时 | 19:00-21:00 | 戌 |

### 1.6 真太阳时修正

**为什么需要真太阳时：**
- 我们使用的是平太阳时（标准时间）
- 古代使用的是真太阳时（根据太阳实际位置）
- 两者之间有时差（-14分钟到+16分钟）

**修正公式：**
```javascript
function calculateTrueSolarTime(
  date: Date,
  longitude: number  // 经度
): Date {
  // 1. 计算时区修正
  const timezoneOffset = (longitude - 120) * 4;  // 分钟

  // 2. 计算真太阳时修正（需要查表或公式计算）
  const equation = calculateEquationOfTime(date);

  // 3. 总修正时间
  const totalOffset = timezoneOffset + equation;

  return new Date(date.getTime() + totalOffset * 60 * 1000);
}
```

### 1.7 十神计算

**十神：** 表示日主与其他天干的关系

**十神定义：**
- **比肩**：与日干同性同五行（如甲见甲）
- **劫财**：与日干异性同五行（如甲见乙）
- **食神**：日干所生同性（如甲见丙）
- **伤官**：日干所生异性（如甲见丁）
- **偏财**：日干所克同性（如甲见戊）
- **正财**：日干所克异性（如甲见己）
- **七杀**：克日干同性（如甲见庚）
- **正官**：克日干异性（如甲见辛）
- **偏印**：生日干同性（如甲见壬）
- **正印**：生日干异性（如甲见癸）

**计算逻辑：**
```javascript
function calculateShiShen(dayGan: string, otherGan: string): string {
  const dayWuxing = ganToWuxing(dayGan);
  const otherWuxing = ganToWuxing(otherGan);
  const dayYinYang = ganYinYang(dayGan);
  const otherYinYang = ganYinYang(otherGan);

  // 同五行
  if (dayWuxing === otherWuxing) {
    return dayYinYang === otherYinYang ? '比肩' : '劫财';
  }

  // 日干生他干
  if (wuxingSheng(dayWuxing, otherWuxing)) {
    return dayYinYang === otherYinYang ? '食神' : '伤官';
  }

  // 日干克他干
  if (wuxingKe(dayWuxing, otherWuxing)) {
    return dayYinYang === otherYinYang ? '偏财' : '正财';
  }

  // 他干克日干
  if (wuxingKe(otherWuxing, dayWuxing)) {
    return dayYinYang === otherYinYang ? '七杀' : '正官';
  }

  // 他干生日干
  if (wuxingSheng(otherWuxing, dayWuxing)) {
    return dayYinYang === otherYinYang ? '偏印' : '正印';
  }
}
```

### 1.9 大运计算

#### 1.9.1 起运年龄

**规则：**
- 阳男阴女：顺数到下一个节气
- 阴男阳女：逆数到上一个节气
- 3天为1年

**代码示例：**
```javascript
function calculateDayunStart(
  birthDate: Date,
  gender: 'male' | 'female',
  yearGan: string
): number {
  const isYangYear = ['甲', '丙', '戊', '庚', '壬'].includes(yearGan);
  const isShun = (gender === 'male' && isYangYear) || (gender === 'female' && !isYangYear);

  let targetJieqi;
  if (isShun) {
    targetJieqi = getNextJieqi(birthDate);
  } else {
    targetJieqi = getPrevJieqi(birthDate);
  }

  const daysDiff = Math.abs(daysBetween(birthDate, targetJieqi));
  const startAge = Math.floor(daysDiff / 3);

  return startAge;
}
```

#### 1.9.2 大运排列

**大运：** 10年为一步，共8步大运

```javascript
function calculateDayun(monthPillar: Pillar, isShun: boolean): Pillar[] {
  const dayunList = [];
  let currentIndex = getSixtyJiaziIndex(monthPillar);

  for (let i = 0; i < 8; i++) {
    if (isShun) {
```

## 2. 易经占卜逻辑

### 2.1 六爻起卦

#### 2.1.1 摇卦法（铜钱法）

**原理：** 使用3枚铜钱，摇6次，每次记录结果

**规则：**
- 正面（字）记为2
- 反面（背）记为3
- 每次总和判断：
  - 6（老阴）→ 阴爻，会变
  - 7（少阳）→ 阳爻，不变
  - 8（少阴）→ 阴爻，不变
  - 9（老阳）→ 阳爻，会变

**代码实现：**
```javascript
function yaogua(): Hexagram {
  const yaos = [];

  for (let i = 0; i < 6; i++) {
    // 模拟抛3枚硬币
    const coin1 = Math.random() > 0.5 ? 2 : 3;
    const coin2 = Math.random() > 0.5 ? 2 : 3;
    const coin3 = Math.random() > 0.5 ? 2 : 3;
    const sum = coin1 + coin2 + coin3;

    let yao;
    let dong = false;
    if (sum === 6) { yao = 0; dong = true; }       // 老阴（动爻）
    else if (sum === 7) { yao = 1; dong = false; } // 少阳
    else if (sum === 8) { yao = 0; dong = false; } // 少阴
    else if (sum === 9) { yao = 1; dong = true; }  // 老阳（动爻）

    yaos.push({ value: yao, dong });
  }

  return generateHexagram(yaos);
}
```

#### 2.1.2 时间起卦法

**公式：**
```
上卦 = (年 + 月 + 日) % 8
下卦 = (年 + 月 + 日 + 时) % 8
动爻 = (年 + 月 + 日 + 时) % 6
```

**示例：**
```
2023年12月25日15时起卦：
年 = 2023
月 = 12
日 = 25
时 = 15

上卦 = (2023 + 12 + 25) % 8 = 2060 % 8 = 4 → 震卦
下卦 = (2023 + 12 + 25 + 15) % 8 = 2075 % 8 = 3 → 离卦
动爻 = (2023 + 12 + 25 + 15) % 6 = 2075 % 6 = 5 → 第5爻

主卦：雷火丰（震上离下）
变卦：第5爻变
```
