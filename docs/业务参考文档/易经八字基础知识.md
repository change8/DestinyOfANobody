## 一、易经基础

### 1.1 易经概述

**易经（周易）：** 中国最古老的经典之一，是一部关于变化的哲学著作。

**核心思想：**
> "一阴一阳之谓道，生生之谓易"

**三易：**
- **简易**：万物变化虽复杂，但有规律可循
- **变易**：万事万物都在变化
- **不易**：变化中有不变的原则

### 1.2 阴阳学说

**阴阳：** 万物的两种基本属性

| 阴 | 阳 |
|----|-----|
| 女、月、夜、冷、静、柔、下、内 | 男、日、昼、热、动、刚、上、外 |
| ☷（断开）| ☰（连续）|

**阴阳关系：**
- **对立**：阴阳相反
- **统一**：阴阳相依
- **消长**：阴消则阳长
- **转化**：阴极生阳，阳极生阴

### 1.3 八卦

**八卦：** 由三个爻（阴爻或阳爻）组成的符号

| 卦名 | 符号 | 自然 | 方位 | 五行 | 家庭 |
|------|------|------|------|------|------|
| 乾 | ☰ | 天 | 西北 | 金 | 父 |
| 坤 | ☷ | 地 | 西南 | 土 | 母 |
| 震 | ☳ | 雷 | 东 | 木 | 长男 |
| 巽 | ☴ | 风 | 东南 | 木 | 长女 |
| 坎 | ☵ | 水 | 北 | 水 | 中男 |
| 离 | ☲ | 火 | 南 | 火 | 中女 |
| 艮 | ☶ | 山 | 东北 | 土 | 少男 |
| 兑 | ☱ | 泽 | 西 | 金 | 少女 |

**八卦记忆口诀：**
```
乾三连，坤六断，
震仰盂，艮覆碗，
离中虚，坎中满，
兑上缺，巽下断。
```

### 1.4 六十四卦

**六十四卦：** 由两个八卦（上卦和下卦）组成，共64种组合

**示例：**
```
䷀ 乾为天（乾上乾下）
䷁ 坤为地（坤上坤下）
䷂ 水雷屯（坎上震下）
䷃ 山水蒙（艮上坎下）
...
```

**卦辞：** 每卦的总体判断
**爻辞：** 每一爻的具体判断（初、二、三、四、五、上）

### 1.5 系辞传

**系辞传：** 《易经》的重要注解，阐述易学哲理

**重要观点：**
- "易有太极，是生两仪，两仪生四象，四象生八卦"
- "天地定位，山泽通气，雷风相薄，水火不相射"
- "穷则变，变则通，通则久"

**推荐阅读：**
- 《周易·系辞传》原文
- 南怀瑾《易经杂说》

#### 六十甲子

**定义：** 天干和地支组合，共60种组合，称为六十甲子

**组合规则：**

- 从"甲子"开始，依次循环

### 2.2 五行学说

#### 五行基础

**五行：** 金、木、水、火、土

| 五行 | 方位 | 季节 | 颜色 | 味道 | 脏腑 | 性格 |
|------|------|------|------|------|------|------|
| 木 | 东 | 春 | 青 | 酸 | 肝 | 仁慈 |
| 火 | 南 | 夏 | 红 | 苦 | 心 | 热情 |
| 土 | 中 | 长夏 | 黄 | 甘 | 脾 | 诚信 |
| 金 | 西 | 秋 | 白 | 辛 | 肺 | 刚毅 |
| 水 | 北 | 冬 | 黑 | 咸 | 肾 | 智慧 |

#### 五行相生

```
木生火 → 火生土 → 土生金 → 金生水 → 水生木
```

**含义：**
- 木生火：木材燃烧生火
- 火生土：火焚木成灰（土）
- 土生金：土中藏金
- 金生水：金属融化成液体
- 水生木：水滋养树木

#### 五行相克

```
木克土 → 土克水 → 水克火 → 火克金 → 金克木
```

**含义：**
- 木克土：树木吸收土壤养分
- 土克水：土能挡水
- 水克火：水能灭火
- 火克金：火能熔金
- 金克木：金属能砍木

### 2.3 四柱八字

#### 四柱构成

**四柱：** 年柱、月柱、日柱、时柱
**八字：** 四柱的天干地支，共8个字

**示例：**
```
某人生于1990年1月1日12:30

年柱：己巳（1989年，因未过立春）
月柱：丙子（十一月）
日柱：丁未
时柱：丙午

八字：己巳 丙子 丁未 丙午
```

#### 日主（日元）

**日主：** 日柱天干，代表本人

上例中，日主为"丁"（火）

### 2.7 十二长生

**十二长生：** 描述五行在十二地支中的状态

```
长生 → 沐浴 → 冠带 → 临官 → 帝旺 → 衰 → 病 → 死 → 墓 → 绝 → 胎 → 养
```

**含义：**
- **长生**：如初生婴儿，开始成长
- **帝旺**：如壮年，最旺盛
- **墓**：如入墓，藏而不现
- **绝**：如死绝，气数已尽

**以甲木为例：**
```
甲木长生在亥，沐浴在子，冠带在丑，
临官在寅，帝旺在卯，衰在辰，
病在巳，死在午，墓在未，
绝在申，胎在酉，养在戌。
```

- **驿马星**：变动、出行

- **羊刃**：刚烈、伤灾

## 三、大运与流年

### 3.1 大运

**大运：** 10年为一步，影响10年运势

**起运规则：**
- **阳男阴女**：顺排（从月柱往后推）
- **阴男阳女**：逆排（从月柱往前推）
- **起运年龄**：距离节气天数 ÷ 3

**示例：**
```
阳年（甲丙戊庚壬）出生的男性，从月柱顺排：
月柱为丙子，则大运为：丁丑、戊寅、己卯、庚辰...
```

### 3.2 流年

**流年：** 每一年的运势，以当年的干支为准

**示例：**
```
2023年为癸卯年
2024年为甲辰年
2025年为乙巳年
```

**流年作用：**
- 与命局产生生克关系
- 影响当年吉凶祸福
- 结合大运综合判断

## 四、格局与用神

### 4.1 格局

**格局：** 八字的整体结构和特点

**常见格局：**

#### 正格

- **正官格**：以正官为用神
- **七杀格**：以七杀为用神
- **正财格**：以正财为用神
- **偏财格**：以偏财为用神
- **食神格**：以食神为用神
- **伤官格**：以伤官为用神

#### 特殊格局

- **从格**：日主过弱，顺从强旺之神
  - 从财格、从官杀格、从儿格（食伤）
- **化格**：天干化合成功
- **专旺格**：某一五行极旺

### 4.2 用神

**用神：** 对命局最有利的五行

**选取原则：**
- **扶抑法**：身旺用克泄耗，身弱用生扶
- **调候法**：调节寒暖燥湿
- **病药法**：找出病症，用药治疗
- **通关法**：化解相克为相生

**示例：**
```
八字：己巳 丙子 丁未 丙午
分析：丁火日主，生于冬月（子月）
      火多（丙丁巳午），但冬月寒冷
      需要木生火，取木为用神
      或需要水制火，取水为用神（根据整体平衡）
```

## 六、常见误区

### 6.1 关于算命

❌ **误区1**：算命能改变命运
✅ **正确理解**：算命只是了解趋势，真正改变靠自己努力

❌ **误区2**：八字决定一切
✅ **正确理解**：八字是先天因素，后天环境同样重要

❌ **误区3**：某一年一定会发生某事
✅ **正确理解**：只是某种趋势和可能性，不是100%确定

### 6.2 关于技术实现

❌ **误区1**：排盘很简单，随便算算就行
✅ **正确理解**：需要考虑立春、节气、真太阳时等多种因素

❌ **误区2**：AI可以完全替代命理师
✅ **正确理解**：AI可以辅助，但经验和灵活判断仍需人工

❌ **误区3**：只要排盘准确就够了
✅ **正确理解**：解读比排盘更重要，需要大量学习和实践
