## 第二章：四柱排盘算法

### 2.1 年柱计算

#### 2.1.1 算法原理

年柱以**立春**为界，不是1月1日！

**公式：**
```
1. 获取当年立春精确时间（年、月、日、时、分、秒）
2. 如果 生日时间 < 立春时间：
     actualYear = 当前年份 - 1
   否则：
     actualYear = 当前年份
3. 年干索引 = (actualYear - 4) % 10
4. 年支索引 = (actualYear - 4) % 12
5. 年柱 = 天干[年干索引] + 地支[年支索引]
```

**为什么减4？**
- 公元4年为甲子年
- (4 - 4) % 10 = 0 → 甲
- (4 - 4) % 12 = 0 → 子
- 所以减4后，索引0对应甲子

#### 2.1.2 立春时间计算

**方法A：查表法（推荐）**

预先计算1900-2100年的立春时间，存储为数据表。

**情况1：立春前后出生**
```

- 2000年2月4日20:00出生 → 1999年（己卯年）
- 2000年2月4日21:00出生 → 2000年（庚辰年）
```

```typescript
function calculateYearPillar(
  birthDate: Date,
  options: { timezone?: number } = {}
): Pillar {
  const year = birthDate.getFullYear();

  // 1. 获取立春时间（查表或计算）
  const lichun = getLichunTime(year);

  // 2. 时区处理
  const tz = options.timezone || 8;
  const localBirth = convertToTimezone(birthDate, tz);
  const localLichun = convertToTimezone(lichun, tz);

  // 3. 判断年份
  const actualYear = localBirth < localLichun ? year - 1 : year;

  // 4. 计算干支
  const ganIndex = (actualYear - 4) % 10;
  const zhiIndex = (actualYear - 4) % 12;

  // 5. 处理负数（公元前）
  const finalGanIndex = ganIndex < 0 ? ganIndex + 10 : ganIndex;
  const finalZhiIndex = zhiIndex < 0 ? zhiIndex + 12 : zhiIndex;

  return {
    gan: TIANGAN[finalGanIndex],
    zhi: DIZHI[finalZhiIndex],
    ganIndex: finalGanIndex,
    zhiIndex: finalZhiIndex
  };
}
```

```typescript
function calculateMonthPillar(
  birthDate: Date,
  yearGan: string
): Pillar {
  // 1. 确定月支（根据节气）
  const monthZhi = getMonthZhiByJieqi(birthDate);
  const zhiIndex = DIZHI.indexOf(monthZhi);

  // 2. 确定月干（五虎遁）
  const MONTH_GAN_START = {
    '甲': 2, '己': 2,
    '乙': 4, '庚': 4,
    '丙': 6, '辛': 6,
    '丁': 8, '壬': 8,
    '戊': 0, '癸': 0
  };

  const startIndex = MONTH_GAN_START[yearGan];

  // 3. 计算月干索引
  // 寅=0, 卯=1, 辰=2, ...
  const monthOffset = (zhiIndex - 2 + 12) % 12;
  const ganIndex = (startIndex + monthOffset) % 10;

  return {
    gan: TIANGAN[ganIndex],
    zhi: monthZhi,
    ganIndex,
    zhiIndex
  };
}

function getMonthZhiByJieqi(date: Date): string {
  const jieqiList = [
    { name: '小寒', zhi: '丑' },
    { name: '立春', zhi: '寅' },
    { name: '惊蛰', zhi: '卯' },
    { name: '清明', zhi: '辰' },
    { name: '立夏', zhi: '巳' },
    { name: '芒种', zhi: '午' },
    { name: '小暑', zhi: '未' },
    { name: '立秋', zhi: '申' },
    { name: '白露', zhi: '酉' },
    { name: '寒露', zhi: '戌' },
    { name: '立冬', zhi: '亥' },
    { name: '大雪', zhi: '子' }
  ];

  // 找到当前日期所处的节气区间
  const year = date.getFullYear();
  for (let i = 0; i < jieqiList.length; i++) {
    const current = jieqiList[i];
    const next = jieqiList[(i + 1) % 12];

    const currentTime = getJieqiTime(year, current.name);
    const nextTime = getJieqiTime(
      next.name === '小寒' ? year + 1 : year,
      next.name
    );

    if (date >= currentTime && date < nextTime) {
      return current.zhi;
    }
  }

  throw new Error('无法确定月支');
}
```

### 2.3 日柱计算

日柱是四柱中最复杂的，有多种计算方法。

#### 2.3.1 方法A：基准日推算法（推荐）

**原理：**
- 选择一个已知的基准日
- 计算目标日期与基准日的天数差
- 根据天数差在六十甲子中循环

**基准日：**
- 1900年1月1日 = 甲戌日（六十甲子第10位，索引10）

**公式：**
```
天数差 = 目标日期 - 1900年1月1日（天数）
甲子索引 = (10 + 天数差) % 60
日柱 = 六十甲子[甲子索引]
```

#### 2.3.2 方法B：万年历查表法（最准确）

预先计算1900-2100年每一天的日柱，存储为查表数据。

**优点：** 100%准确
**缺点：** 需要存储大量数据

#### 2.3.3 完整算法

```typescript
function calculateDayPillar(date: Date): Pillar {
  // 基准日：1900-01-01 = 甲戌日（索引10）
  const baseDate = new Date(1900, 0, 1);
  const baseDayIndex = 10;

  // 计算天数差
  const daysDiff = getDaysDifference(baseDate, date);

  // 计算甲子索引
  let jiaziIndex = (baseDayIndex + daysDiff) % 60;

  // 处理负数
  if (jiaziIndex < 0) {
    jiaziIndex += 60;
  }

  // 获取干支
  const ganIndex = jiaziIndex % 10;
  const zhiIndex = jiaziIndex % 12;

  return {
    gan: TIANGAN[ganIndex],
    zhi: DIZHI[zhiIndex],
    ganIndex,
    zhiIndex,
    jiaziIndex
  };
}

// 辅助函数：计算两个日期之间的天数差
function getDaysDifference(date1: Date, date2: Date): number {
  const oneDay = 24 * 60 * 60 * 1000;
  const time1 = date1.getTime();
  const time2 = date2.getTime();

  return Math.floor((time2 - time1) / oneDay);
}
```

#### 2.4.3 真太阳时修正（可选）

**什么是真太阳时？**
- 平太阳时：标准时间（手表时间）
- 真太阳时：根据太阳实际位置计算的时间
- 两者有时差：-14分钟到+16分钟

**是否需要修正？**
- 传统派：必须修正
- 现代派：不需要修正
- **建议：提供选项让用户选择**

**修正公式：**
```
真太阳时 = 平太阳时 + 经度修正 + 时差修正

经度修正 = (当地经度 - 120°) × 4分钟
时差修正 = 查表获取（根据日期）
```

#### 2.4.4 完整算法

```typescript
function calculateHourPillar(
  birthTime: Date,
  dayGan: string,
  options: {
    ziShiMethod?: 'traditional' | 'modern';
    useTrueSolarTime?: boolean;
    longitude?: number;
  } = {}
): Pillar {
  // 1. 真太阳时修正（可选）
  let actualTime = birthTime;
  if (options.useTrueSolarTime && options.longitude) {
    actualTime = convertToTrueSolarTime(birthTime, options.longitude);
  }

  // 2. 获取小时和分钟
  const hour = actualTime.getHours();
  const minute = actualTime.getMinutes();

  // 3. 确定时支
  let zhiIndex: number;
  let isNextDay = false;

  if (hour === 23) {
    // 夜子时
    if (options.ziShiMethod === 'traditional') {
      zhiIndex = 0; // 子
      isNextDay = true; // 算明天
    } else {
      zhiIndex = 0; // 子
      isNextDay = false;
    }
  } else {
    // 其他时辰
    zhiIndex = Math.floor((hour + 1) / 2) % 12;
  }

  // 4. 确定时干（五鼠遁）
  const HOUR_GAN_START = {
    '甲': 0, '己': 0,
    '乙': 2, '庚': 2,
    '丙': 4, '辛': 4,
    '丁': 6, '壬': 6,
    '戊': 8, '癸': 8
  };

  const startIndex = HOUR_GAN_START[dayGan];
  const ganIndex = (startIndex + zhiIndex) % 10;

  return {
    gan: TIANGAN[ganIndex],
    zhi: DIZHI[zhiIndex],
    ganIndex,
    zhiIndex,
    isNextDay // 是否算第二天
  };
}

// 真太阳时转换
function convertToTrueSolarTime(
  time: Date,
  longitude: number
): Date {
  // 1. 经度修正（东八区为基准120°）
  const longitudeOffset = (longitude - 120) * 4; // 分钟

  // 2. 时差修正（查表）
  const equationOfTime = getEquationOfTime(time);

  // 3. 总修正
  const totalOffset = longitudeOffset + equationOfTime;

  return new Date(time.getTime() + totalOffset * 60 * 1000);
}
```

```typescript
function calculateShiShen(
  dayGan: string,
  otherGan: string
): string {
  // 1. 获取五行
  const dayWuxing = GAN_WUXING[dayGan];
  const otherWuxing = GAN_WUXING[otherGan];

  // 2. 判断阴阳
  const sameYinYang = (GAN_YINYANG[dayGan] === GAN_YINYANG[otherGan]);

  // 3. 判断关系
  if (dayWuxing === otherWuxing) {
    // 同五行
    return sameYinYang ? '比肩' : '劫财';
  } else if (wuxingSheng(dayWuxing, otherWuxing)) {
    // 我生
    return sameYinYang ? '食神' : '伤官';
  } else if (wuxingKe(dayWuxing, otherWuxing)) {
    // 我克
    return sameYinYang ? '偏财' : '正财';
  } else if (wuxingKe(otherWuxing, dayWuxing)) {
    // 克我
    return sameYinYang ? '七杀' : '正官';
  } else if (wuxingSheng(otherWuxing, dayWuxing)) {
    // 生我
    return sameYinYang ? '偏印' : '正印';
  }

  throw new Error('无法确定十神关系');
}
```

## 第四章：大运流年计算

### 4.1 起运年龄

**规则：**
```
阳年生男、阴年生女：顺排，数到下一个节气
阴年生男、阳年生女：逆排，数到上一个节气

起运岁数 = 天数 ÷ 3
```

**阳年：** 甲、丙、戊、庚、壬
**阴年：** 乙、丁、己、辛、癸

### 4.2 大运排列

**规则：**
- 10年一步大运
- 从月柱开始，顺排或逆排
- 共8步大运

```typescript
function calculateDayun(
  monthPillar: Pillar,
  birthDate: Date,
  gender: 'male' | 'female',
  yearGan: string
): Dayun[] {
  // 1. 判断顺逆
  const yangYear = ['甲', '丙', '戊', '庚', '壬'].includes(yearGan);
  const isShun = (gender === 'male' && yangYear) ||
                 (gender === 'female' && !yangYear);

  // 2. 计算起运年龄
  const startAge = calculateQiyunAge(birthDate, isShun);

  // 3. 排大运
  const dayunList: Dayun[] = [];
  let currentIndex = monthPillar.jiaziIndex;

  for (let i = 0; i < 8; i++) {
    // 顺逆推算
    if (isShun) {
      currentIndex = (currentIndex + 1) % 60;
    } else {
      currentIndex = (currentIndex - 1 + 60) % 60;
    }

    const ganIndex = currentIndex % 10;
    const zhiIndex = currentIndex % 12;

    dayunList.push({
      gan: TIANGAN[ganIndex],
      zhi: DIZHI[zhiIndex],
      startAge: startAge + i * 10,
      endAge: startAge + (i + 1) * 10 - 1
    });
  }

  return dayunList;
}
```

## 第六章：异常情况处理

### 6.1 边界情况

1. **立春前后数分钟出生**
   - 建议：精确到分秒判断
   - 如果时间恰好等于立春时间，算新年

2. **子时前后出生**
   - 23:00:00 算第二天
   - 00:59:59 算当天
   - 提供选项让用户选择

3. **公元前日期**
   - 需要特殊处理负数取模
   - JavaScript的%运算符对负数处理不同

4. **闰年2月29日**
   - 正常处理，不影响干支计算

### 6.2 输入验证

```typescript
function validateBirthInput(input: {
  date: Date;
  time: string;
  gender: string;
}) {
  // 1. 日期范围验证
  const minDate = new Date(1900, 0, 1);
  const maxDate = new Date(2100, 11, 31);

  if (input.date < minDate || input.date > maxDate) {
    throw new Error('日期超出支持范围（1900-2100）');
  }

  // 2. 时间格式验证
  const timeRegex = /^([01]\d|2[0-3]):([0-5]\d)$/;
  if (!timeRegex.test(input.time)) {
    throw new Error('时间格式错误，应为 HH:mm');
  }

  // 3. 性别验证
  if (!['male', 'female'].includes(input.gender)) {
    throw new Error('性别必须为 male 或 female');
  }
}
```
