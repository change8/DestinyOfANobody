# 产品设计文档

## 1. 产品概述

### 1.1 产品定位

**命运之道**是一款专注于传统易经、八字命理的微信小程序，面向对传统文化和命理学感兴趣的用户，提供专业、准确、易用的命理分析服务。

**核心价值主张：**
- 传承传统：遵循《周易》《子平真诠》等经典命理理论
- 科学实现：使用现代算法精准计算，避免人工排盘误差
- 深度解读：不仅提供排盘结果，更提供命理解读和人生建议
- 用户友好：简化复杂的命理概念，让普通用户也能理解

### 1.2 目标用户

**主要用户画像：**

1. **命理爱好者**（40%）
   - 年龄：25-45岁
   - 对易经、八字有一定了解
   - 希望深入学习命理知识
   - 需要专业的排盘工具

2. **好奇探索者**（35%）
   - 年龄：20-35岁
   - 对传统文化好奇
   - 希望了解自己的运势
   - 娱乐为主，学习为辅

3. **人生迷茫者**（25%）
   - 年龄：30-50岁
   - 面临人生重要选择
   - 希望获得指引和建议
   - 关注事业、婚姻、健康等

### 1.3 竞品分析

| 产品 | 优势 | 劣势 | 我们的差异化 |
|------|------|------|--------------|
| 元亨利贞 | 资料全面，历史悠久 | 界面老旧，操作复杂 | 现代化UI，简化操作流程 |
| 灵机妙算 | 功能丰富，商业化成熟 | 过度商业化，准确性存疑 | 专注核心功能，算法透明 |
| 生辰八字排盘 | 排盘准确 | 缺少解读，纯工具 | 提供深度解读和建议 |

## 3. 功能详细设计

### 3.1 八字排盘功能

#### 3.1.1 输入界面

**输入信息：**
- 公历生日：年/月/日/时
- 性别：男/女（用于大运顺逆）
- 时区：默认东八区（支持手动调整）
- 是否夏令时：可选

**交互设计：**
- 使用日期选择器组件
- 时辰选择使用下拉列表（子时、丑时...）
- 提供"不知道时辰"选项，按子时起盘
- 支持保存多个常用生辰

#### 3.1.2 排盘结果展示

**四柱展示：**
```
         年柱    月柱    日柱    时柱
天干：    癸      甲      丁      庚
地支：    卯      寅      未      子
纳音：   金箔金  大溪水  天河水  壁上土
十神：    正印    偏印    日主    正财
藏干：    乙     甲丙戊    乙己丁    癸
```

**五行强弱分析：**
- 五行个数统计（木、火、土、金、水）
- 五行力量百分比
- 五行旺衰判断
- 喜用神分析

**大运排列：**
- 起运年龄计算
- 10年一步大运
- 大运干支展示
- 流年对照表

#### 3.1.3 命理解读

**基础解读：**
- 日主强弱
- 格局判断（正格、从格、化格等）
- 用神、忌神
- 性格特点

**多维度分析：**
1. **事业运**：事业方向、适合行业、发展时期
2. **财富运**：财运强弱、求财方式、财运高峰
3. **婚姻运**：婚姻状况、配偶特征、婚姻时期
4. **健康运**：体质特点、易患疾病、注意事项
5. **六亲运**：父母、兄弟、子女、配偶关系

### 3.2 易经占卜功能

#### 3.2.1 六爻起卦

**起卦方式：**
1. **摇卦法**：模拟铜钱摇卦（点击按钮6次）
2. **时间起卦**：根据当前时间自动起卦
3. **数字起卦**：输入两个数字起卦
4. **问题起卦**：输入问题，系统生成卦象

**卦象展示：**
```
主卦：  ䷀ 乾为天
六爻：
上九：  ━━━  亢龙有悔
九五：  ━━━  飞龙在天
九四：  ━━━  或跃在渊
九三：  ━━━  君子终日乾乾
九二：  ━━━  见龙在田
初九：  ━━━  潜龙勿用

变卦：  ䷁ 坤为地
```

**卦象解读：**
- 卦辞解释
- 爻辞分析
- 用神提取
- 事态发展趋势
- 建议和指导

#### 3.2.2 梅花易数

**起卦方式：**
- 报数起卦
- 时间起卦
- 声音起卦
- 方位起卦

**分析内容：**
- 体卦、用卦
- 互卦、变卦
- 五行生克
- 吉凶判断

### 3.3 人生K线图

**灵感来源：** 参考 lifekline 项目

**数据维度：**
- X轴：年龄（1-100岁）
- Y轴：运势强度（0-100）
- K线四值：开盘（年初）、收盘（年末）、最高、最低

**计算逻辑：**
- 基于大运流年的天干地支
- 结合用神喜忌
- 五行力量对比
- 重大流年标注（结婚、事业、财运等）

**可视化展示：**
- 使用 echarts 绘制K线图
- 红色表示上升运势
- 绿色表示下降运势
- 点击年份查看详细解读

## 5. 界面设计规范

### 5.1 设计风格

**整体风格：**
- 中国传统文化风格
- 配色：青色、金色为主
- 字体：楷体、宋体（标题）、黑体（正文）
- 元素：水墨、祥云、八卦纹等传统图案

**色彩方案：**
- 主色：#1A4D2E（墨绿）
- 辅助色：#C9A961（金色）
- 背景色：#F5F0E8（米黄）
- 文字色：#2C2C2C（深灰）
- 强调色：#B22222（朱红）

### 5.2 组件设计

**卡片组件：**
- 圆角：8px
- 阴影：0 2px 8px rgba(0,0,0,0.1)
- 边框：1px solid #E5DCC8

**按钮组件：**
- 主按钮：金色渐变背景
- 次按钮：描边样式
- 禁用态：灰色半透明

## 6. 数据与隐私

### 6.1 数据收集

**必要数据：**
- 生辰信息（用于排盘计算）
- 微信昵称、头像（用于用户识别）
- 使用记录（用于优化体验）

**可选数据：**
- 地理位置（用于真太阳时修正）
- 分享行为（用于推广统计）

### 6.2 隐私保护

**承诺：**
- 生辰信息仅存储在用户个人账户
- 不对外公开或售卖用户数据
- 用户可随时删除个人数据
- 所有数据传输使用HTTPS加密

## 9. 风险与应对

### 9.1 技术风险

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 排盘算法不准确 | 用户信任度下降 | 对比多个权威排盘工具验证，建立测试用例库 |
| 服务器性能问题 | 用户体验差 | 引入缓存机制，优化算法，使用CDN |
| 数据库故障 | 数据丢失 | 定期备份，主从同步，灾备方案 |

### 9.2 合规风险

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 微信小程序审核不通过 | 无法上线 | 淡化"算命"字眼，强调文化传承和娱乐性 |
| 涉嫌封建迷信 | 被下架 | 添加免责声明，仅供娱乐参考 |
| 用户隐私泄露 | 法律风险 | 严格数据安全管理，隐私协议 |

### 9.3 运营风险

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 用户增长缓慢 | 无法达到目标 | 社交裂变，内容营销，KOL推广 |
| 竞品压力 | 市场份额低 | 差异化定位，专注核心用户 |
| 内容质量不足 | 用户流失 | 聘请专业命理师审核，建立内容质量标准 |
