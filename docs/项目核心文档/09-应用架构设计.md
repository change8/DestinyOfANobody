## 🗄️ 数据库设计

### 表结构设计

#### 1. users 表（用户表）

```sql
CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  username VARCHAR(50) UNIQUE NOT NULL,
  email VARCHAR(100) UNIQUE NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  nickname VARCHAR(50),
  avatar_url VARCHAR(255),
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  last_login_at DATETIME,
  is_active BOOLEAN DEFAULT TRUE
);

CREATE INDEX idx_users_email ON users(email);
CREATE INDEX idx_users_username ON users(username);
```

#### 2. divination_records 表（占卜记录表）

```sql
CREATE TABLE divination_records (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL,
  type VARCHAR(20) NOT NULL,  -- 'bazi' 或 'meihua'
  title VARCHAR(100),
  question TEXT,
  input_data JSON NOT NULL,    -- 存储输入参数（JSON）
  result_data JSON NOT NULL,   -- 存储占卜结果（JSON）
  llm_interpretation TEXT,     -- LLM 解读内容
  llm_model VARCHAR(50),       -- 使用的 LLM 模型
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  is_favorite BOOLEAN DEFAULT FALSE,
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

CREATE INDEX idx_records_user_id ON divination_records(user_id);
CREATE INDEX idx_records_type ON divination_records(type);
CREATE INDEX idx_records_created_at ON divination_records(created_at DESC);
```

#### 3. user_preferences 表（用户偏好设置表）

```sql
CREATE TABLE user_preferences (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER UNIQUE NOT NULL,
  default_llm_provider VARCHAR(20),  -- 'openai', 'anthropic', 'zhipu' 等
  default_llm_model VARCHAR(50),
  theme VARCHAR(10) DEFAULT 'light',  -- 'light' 或 'dark'
  language VARCHAR(10) DEFAULT 'zh-CN',
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);
```

## 🔐 认证流程

### JWT 认证机制

1. **用户登录**:
   - 用户提交邮箱和密码
   - 服务器验证凭据
   - 生成 JWT token（有效期 7 天）
   - 返回 token 给客户端

2. **Token 存储**:
   - 客户端将 token 存储在 localStorage
   - 每次请求在 Authorization header 中携带

3. **Token 验证**:
   - 服务器中间件验证 token
   - 解析用户 ID
   - 注入到 req.user

4. **Token 刷新**:
   - Token 过期前可以刷新
   - 或重新登录获取新 token

## 🤖 LLM 集成流程

### 解读流程

1. **用户选择 LLM 提供商和模型**
2. **构建提示词**:
   - 根据占卜类型（八字/梅花）
   - 包含完整的占卜结果
   - 用户的具体问题
3. **调用 LLM API**:
   - 使用已有的 `src/llm/client.ts`
   - 流式或非流式返回
4. **展示解读结果**:
   - 前端渲染 Markdown 格式
   - 保存到数据库
