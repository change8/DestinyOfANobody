## Module 101: 八字排盘模块 (BaZi Calculator)

### 核心功能

#### 1.1 四柱计算 (Four Pillars)
**输入**：
```typescript
{
  birthDate: '1990-01-01',
  birthTime: '12:30',
  gender: 'male',
  longitude: 116.4074  // 可选，用于真太阳时
}
```

**输出**：
```typescript
{
  pillars: {
    year: { gan: '庚', zhi: '午', nayin: '路旁土' },
    month: { gan: '丁', zhi: '丑', nayin: '涧下水' },
    day: { gan: '甲', zhi: '子', nayin: '海中金' },
    hour: { gan: '庚', zhi: '午', nayin: '路旁土' }
  }
}
```

**关键算法**：
- ✅ 年柱：基于立春节气（非春节）
- ✅ 月柱：基于节气（如寅月从立春到惊蛰）
- ✅ 日柱：干支纪日连续计数
- ✅ 时柱：五鼠遁起时干

**难点**：
- 子时的处理（早子时算当天，晚子时算次日）
- 真太阳时修正（经度不同，时间不同）

---

#### 1.2 五行分析 (Wuxing Analysis)
**统计**：八字中的金木水火土个数

**强弱判断**：
- 日主得令（出生月份的五行）
- 日主得地（地支中的比劫）
- 日主得生（印星的个数）
- 日主得助（比肩、劫财）

**输出**：
```typescript
{
  wuxing: {
    木: 2, 火: 1, 土: 2, 金: 2, 水: 1
  },
  strength: '中和',
  favorable: ['木', '水'],  // 喜用神
  unfavorable: ['土', '金'] // 忌神
}
```

---

#### 1.3 十神计算 (Shishen)
**定义**：
- 比肩、劫财（同我者）
- 食神、伤官（我生者）
- 正财、偏财（我克者）
- 正官、七杀（克我者）
- 正印、偏印（生我者）

**关系表**：

| 日主 | 比肩 | 劫财 | 食神 | 伤官 | 正财 | 偏财 | 正官 | 七杀 | 正印 | 偏印 |
|------|------|------|------|------|------|------|------|------|------|------|
| 甲木 | 甲 | 乙 | 丙 | 丁 | 戊 | 己 | 庚 | 辛 | 壬 | 癸 |

**输出**：
```typescript
{
  shishen: {
    year: '偏印',
    month: '正财',
    day: '日主',
    hour: '偏印'
  }
}
```

---

#### 1.4 大运流年 (Dayun & Liunian)
**大运计算**：
- 男阳年、女阴年顺行
- 男阴年、女阳年逆行
- 每步大运10年

**流年计算**：
- 从出生年开始的每一年
- 计算与八字的关系

**输出**：
```typescript
{
  dayun: [
    { age: 3, gan: '戊', zhi: '寅', nayin: '城墙土' },
    { age: 13, gan: '己', zhi: '卯', nayin: '城墙土' },
    // ...
  ],
  liunian: [
    { year: 2024, gan: '甲', zhi: '辰', age: 34 },
    // ...
  ]
}
```

## Module 102: 梅花易数模块 (Meihua Yishu)

### 核心功能

#### 2.1 起卦系统 (Qigua)

##### 2.1.1 字占 (Character Divination)
**当前实现**：
```typescript
const gua = qiguaByChar('找');
// 分析：笔画数7 + 字义分析 + 部首分析
```

**多维度分析**：
- **笔画数**：找=7画 → 7%8=7 → 艮卦
- **字义**：找=寻找、搜索 → 震、艮卦
- **部首**：扌（手旁）→ 木行 → 震卦
- **结构**：左右结构 → 有分离之象

**未来扩展**：
- 🔄 声调起卦（平仄声调对应不同卦）
- 🔄 字形起卦（独体/合体/象形等）

---

##### 2.1.2 数字占 (Number Divination)
```typescript
const gua = qiguaByNumber(3, 7);
// 上卦: 3%8=3 → 离卦
// 下卦: 7%8=7 → 艮卦
// 动爻: (3+7)%6=4 → 四爻动
```

---

##### 2.1.3 时间占 (Time Divination)
```typescript
const gua = qiguaByTime(new Date());
// 年月日时之和起卦
```

---

##### 2.1.4 方位占 (Direction Divination) 🚧 规划中
**设计**：
```typescript
const gua = qiguaByDirection({
  direction: '东南',
  userLocation: { lat: 39.9, lon: 116.4 }
});
```

**映射关系**：
- 东方 → 震卦
- 东南 → 巽卦
- 南方 → 离卦
- 西南 → 坤卦
- 西方 → 兑卦
- 西北 → 乾卦
- 北方 → 坎卦
- 东北 → 艮卦

---

##### 2.1.5 环境占 (Environment Divination) 🚧 规划中
**用户输入**：
- 看到的颜色（红→离、黑→坎）
- 听到的声音（雷→震、风→巽）
- 周围物象（山→艮、水→坎）

**示例**：
```typescript
const gua = qiguaByEnvironment({
  观察: {
    看到: ['红色', '火光'],
    听到: ['风声'],
    感觉: ['温暖']
  }
});
// 推断: 离卦(火)+巽卦(风) → 火风鼎
```

---

#### 2.2 断卦系统 (Duangua)

##### 2.2.1 体用论 (Tigua-Yonggua)
**核心理论**：
- 动爻在上卦 → 上卦为用，下卦为体
- 动爻在下卦 → 下卦为用，上卦为体

**五行生克关系**：
```
体克用：可寻迟得（能找到，但费力）
用克体：不可寻（很难找到）
体生用：物难见（物品远离）
用生体：物易寻（很容易找到）
比和：物不失（物品未丢失）
```

**实现**：
```typescript
const tiYongAnalysis = analyzeTiYong(gua);
console.log(tiYongAnalysis.失物判断);
// {
//   能否找到: true,
//   难易程度: '容易',
//   寻找建议: '物品未丢失，仔细找找就能发现'
// }
```

---

##### 2.2.2 互卦分析 (Hugua)
**取法**：
- 下互卦：2、3、4爻
- 上互卦：3、4、5爻

**意义**：代表事物发展的中间过程

**示例**：
```
本卦：水山蹇 ☵☶
  上爻 ○
  五爻 ●
  四爻 ○  ┐
  三爻 ○  ├→ 上互：艮 ☶
  二爻 ○  ┘
  初爻 ○

互卦：艮坤 → 地山谦
```

---

##### 2.2.3 失物占 (Lost Item Divination)
**输出**：
- 物品特征（形状、颜色、材质）
- 位置信息（方位、高低、内外）
- 时间判断（能否找到、预计时间）

**示例**：
```typescript
const result = divineForLostItem(gua, '钥匙丢了', '钥匙');

console.log(result.location.方位);     // "东北"
console.log(result.location.具体位置); // ["门后", "墙角", "柜顶"]
console.log(result.timing.能否找到);   // true
```

---

##### 2.2.4 射覆 (Shefu - Object Guessing)
**功能**：根据卦象猜测隐藏的物品

**示例**：
```typescript
const result = sheFu(gua);
console.log(result.可能物品); // ["羊", "鸡", "玉器", "圆形物"]
console.log(result.物品特征); // "形状：圆形或球形；颜色：白色或金色"
```

---

#### 2.3 交互式占卜系统 (Interactive Divination)
**特点**：多轮对话，逐步逼近真相

**流程**：
```
1. initial   : 初步起卦，确认方位
2. direction : 缩小方位范围
3. location  : 确定具体位置
4. features  : 确认物品特征
5. timing    : 观察外应
6. final     : 最终结论
```

**示例**：
```typescript
// 第1轮
const session = createDivinationSession('钥匙丢了', gua, '字占-找');
const step1 = getNextStep(session);
console.log(step1.question);
// "根据卦象，初步判断方位在东北或东北。请问这个方位判断是否符合您的实际情况？"

// 用户反馈
const feedback = {
  准确性: 'partial',
  额外信息: { 再起一字: '家', 看到颜色: ['黄色'] }
};

// 第2轮
const { updatedSession, nextStep, analysis } = processFeedback(session, feedback);
console.log(analysis);
// "【新字分析】'家'字：住所、稳定，对应坤艮卦..."
```

## Module 103: 基础数据模块 (Data Module)

### 3.1 农历数据 (Lunar Calendar)
**范围**：1900-2100年

**数据结构**：
```typescript
{
  1900: 0x04bd8,  // 位编码
  // 每个数字包含：
  // - 12个月的大小月信息
  // - 闰月位置
  // - 春节日期
}
```

**功能**：
- 阳历转农历
- 农历转阳历
- 闰月处理

**文件**：`src/data/lunar-data.ts`

---

### 3.2 二十四节气 (Solar Terms)
**数据**：每年24个节气的精确时刻

**用途**：
- 确定月柱（如立春到惊蛰为寅月）
- 确定年柱（立春前算上一年）

**算法**：寿星天文历算法（精度±1分钟）

**文件**：`src/data/solar-terms.ts`
