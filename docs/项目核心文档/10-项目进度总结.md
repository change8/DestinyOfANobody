**已实现的 API**:

1. **认证模块** `/api/auth` ✅
   - POST `/register` - 用户注册
   - POST `/login` - 用户登录
   - GET `/me` - 获取当前用户

2. **占卜模块** `/api/divination` ✅
   - POST `/bazi` - 八字排盘（集成核心算法）
   - POST `/meihua` - 梅花易数（集成核心算法）
   - 支持可选认证（登录用户自动保存历史）

3. **历史记录模块** `/api/history` ✅
   - GET `/` - 获取列表（分页、筛选）
   - GET `/:id` - 获取详情
   - DELETE `/:id` - 删除记录
   - PUT `/:id/favorite` - 收藏/取消收藏

4. **健康检查** ✅
   - GET `/health` - 服务状态

**数据库表**:
- `users` - 用户表（id, username, email, password_hash, nickname, etc.）
- `divination_records` - 占卜记录（id, user_id, type, input_data, result_data, llm_interpretation, etc.）
- `user_preferences` - 用户偏好（id, user_id, default_llm_provider, theme, etc.）

## 🔧 如何运行（当前可用）

### 后端服务
```bash
cd server
npm run dev
# 服务运行在 http://localhost:3000
```

**测试端点**:
```bash
# 健康检查
curl http://localhost:3000/health

# 用户注册
curl -X POST http://localhost:3000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"test","email":"test@example.com","password":"123456"}'

# 用户登录

  -H "Content-Type: application/json" \
```
