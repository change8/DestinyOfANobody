# 梅花易数模块设计方案

## 功能概述

实现梅花易数占卜系统，支持失物占、射覆等应用场景。

## 核心功能

### 1. 起卦方法（多种输入）

#### 1.1 字占起卦
```typescript
interface CharDivination {
  char: string;           // 用户输入的字
  strokeCount: number;    // 笔画数
  upperGua: Gua;         // 上卦
  lowerGua: Gua;         // 下卦
  changingLine: number;  // 动爻
  resultGua: Gua;        // 变卦
}

// 示例：用户写"水"字
// 1. 获取笔画数：4画
// 2. 上卦 = 4 % 8 = 4（震卦）
// 3. 下卦 = 4 % 8 = 4（震卦）
// 4. 动爻 = 4 % 6 = 4
// 5. 得卦：震为雷，四爻动，变卦为震卦
```

#### 1.2 数字起卦
```typescript
interface NumberDivination {
  number1: number;       // 第一个数（上卦）
  number2?: number;      // 第二个数（下卦，可选）
  time?: Date;           // 时间（用于动爻，可选）
  upperGua: Gua;
  lowerGua: Gua;
  changingLine: number;
  resultGua: Gua;
}

// 示例：用户报数 3 和 7
// 上卦 = 3 % 8 = 3（离卦）
// 下卦 = 7 % 8 = 7（艮卦）
// 动爻 = (3 + 7) % 6 = 4
// 得卦：火山旅
```

#### 1.3 时间起卦
```typescript
// 根据占卜时的年月日时起卦
// 上卦 = (年数 + 月数 + 日数) % 8
// 下卦 = (年数 + 月数 + 日数 + 时数) % 8
// 动爻 = (年数 + 月数 + 日数 + 时数) % 6
```

### 3. 断卦分析系统

```typescript
interface DivinationResult {
  // 基础信息
  question: string;           // 问题
  mainGua: string;           // 主卦
  changingGua: string;       // 变卦
  changingLine: number;      // 动爻

  // 物品特征推断
  objectInfo: {
    可能形状: string[];
    可能颜色: string[];
    可能材质: string[];
    物品特征: string[];
  };

  // 位置推断
  locationInfo: {
    方位: string;            // 东南西北
    高低: string;            // 高处、低处
    具体位置: string[];      // 具体可能的位置
    距离: string;            // 近、远
  };

  // 时间推断
  timing: {
    能否找到: boolean;
    预计时间: string;
    吉凶: string;
  };

  // 详细分析
  analysis: {
    卦象分析: string;
    五行分析: string;
    动爻分析: string;
    综合判断: string;
  };
}
```

### 4. 示例应用场景

#### 场景1：丢失钥匙
```
用户输入："家"字
笔画：10画
起卦：
- 上卦：10 % 8 = 2（兑卦）
- 下卦：10 % 8 = 2（兑卦）
- 动爻：10 % 6 = 4（四爻动）
主卦：兑为泽
变卦：泽水困

分析：
- 兑卦特征：金属、白色、有口的地方
- 方位：正西方
- 位置：门口、窗口、低洼处
- 特征：可能在破损的、有开口的容器里
- 时间：近期可找到（兑主悦，困卦暂时困住）
- 结论：钥匙很可能在西边的门口附近，或者某个白色的、有开口的容器里
```

#### 场景2：丢失手机
```
用户报数：3
当前时间起卦
上卦：离（3）
下卦：震（当前时辰）
动爻：...

分析：
- 离卦：电子产品、光亮、红色
- 震卦：东方、动态、有声
- 结论：手机可能在东边或东南方向，可能在动态的地方（如车上、路边），
        或者在有电器的地方，可能会响（震为声）
```

## 技术实现要点

1. **汉字笔画库**：需要一个汉字->笔画数的映射表
2. **六十四卦数据**：完整的64卦名称、卦象、爻辞
3. **类象数据库**：详细的八卦万物类象
4. **五行生克**：用于判断吉凶、远近
5. **动爻变化**：计算变卦
