## 二、起卦方法详解

### 2.1 字占起卦法

**来源**：[国易堂 - 梅花易数测字、字占从一字到十字](https://www.guoyi360.com/mh/cz/2885.html)

#### 基本原则
> 断字法：断开以后按照上卦、下卦、动爻的顺序进行起卦

#### 两种起卦法
1. **笔画起卦法**（本项目已实现）
   - 两个字：前一字笔画数为上卦，后一字为下卦，两字之和为动爻
   - 三个字：前一字为上卦，后两字之和为下卦，三字之和为动爻
   - 四个字：前两字之和为上卦，后两字之和为下卦，四字之和为动爻

2. **声调起卦法**（待实现）
   - 平仄声调对应不同卦数
   - 可与笔画法结合使用

#### 实战案例
**来源**：同上

**李白《黄鹤楼送孟浩然之广陵》案例**：
- 全诗28字
- 上14字，下14字
- 14 ÷ 8 余6 → 坎卦（上卦）
- 28 ÷ 6 余4 → 四爻动
- 得变卦：泽水困

**启示**：
- 可以对整句话、整首诗起卦
- 灵活分段处理

---

### 2.2 时间起卦法

**来源**：[CSDN - 报数起卦方法解析](https://blog.csdn.net/ufo2006/article/details/80643241)

**公式**：
```
上卦 = (年 + 月 + 日) % 8
下卦 = (年 + 月 + 日 + 时) % 8
动爻 = (年 + 月 + 日 + 时) % 6
```

**注意事项**：
- 使用农历年月日
- 时辰用地支序数（子=1，丑=2，...）

---

### 2.3 经典案例：邻夜扣门借物占

**来源**：[知乎 - 梅花易数初体验](https://zhuanlan.zhihu.com/p/589830065)

**事件**：
> 冬夕酉时有人扣门借物

**起卦过程**：
- 敲门声音：一声为乾（上卦）
- 继续敲门：五声为巽（下卦）
- 加时数得天风姤卦第四爻变

**断卦结果**：
- 判断为"借斧"而非"借锄"
- 依据：兑卦（上互）为"缺口"之象，巽卦（风）为"木"，综合判断为"有柄有刃的木制工具"

**关键启示**：
1. **声音可以起卦**：敲门声、说话声、动物叫声
2. **外应很重要**：现场的所有信息都可能是线索
3. **需要灵活变通**：不是死套公式，而是综合判断

## 三、断卦核心理论

### 3.1 体用论（最核心）

**来源**：[知乎 - 半小时学会梅花易数](https://zhuanlan.zhihu.com/p/1940098037251835573)

#### 定义
- **体卦**：无动爻的卦，代表主体、自己、内在
- **用卦**：有动爻的卦，代表外部、事物、他人

#### 判断规则
- 动爻在上卦（4、5、6爻）→ 上卦为用，下卦为体
- 动爻在下卦（1、2、3爻）→ 下卦为用，上卦为体

#### 体用生克关系（失物占核心）

**来源**：[国易堂 - 梅花易数高级断卦实例](https://www.guoyi360.com/mh/rm/100454.html)

```
体克用：可寻迟得（能找到，但需要时间和努力）
用克体：不可寻（很难找到，可能已失）
体生用：物难见（物品远离，耗费精力）
用生体：物易寻（最吉，很容易找到）
比和：物不失（物品未丢失，只是暂时看不到）
```

### 3.2 互卦理论

**来源**：[易安居 - 梅花易数在线排盘](https://m.zhouyi.cc/zhouyi/meihua/)

#### 取法
- **下互卦**：由二、三、四爻组成
- **上互卦**：由三、四、五爻组成

#### 意义
> 互卦代表事物发展的中间过程，是从本卦（现状）到变卦（结果）之间的过渡阶段

#### 示例
```
本卦：水山蹇 ☵☶
  上爻 ○ (坎)
  五爻 ● (坎)
  四爻 ○ (坎) ┐
  三爻 ○ (艮) ├→ 上互卦：艮 ☶
  二爻 ○ (艮) ┘
  初爻 ○ (艮)

下互：二三四爻 → 坤☷
上互：三四五爻 → 艮☶
互卦：地山谦
```

## 四、失物占专论

### 4.1 判断要点

**来源**：[CSDN - 寻物有妙招，梅花易数来帮忙](https://blog.csdn.net/u012146567/article/details/145611350)

#### 三个关键步骤
1. **充分熟悉万物类象**
   - 从变卦的卦象判断寻找失物的方向

2. **丰富的生活常识**
   - 从失物本身的特性入手（大小、属性等）
   - 研究周围环境

3. **缩小范围，锁定位置**
   - 将范围逐步缩小
   - 最终锁定具体位置

#### 失物占公式（本项目已实现）
```
体卦 = 主体（求测者）
用卦 = 失物

体克用：可寻，但费时
用克体：难寻，可能已失
体生用：物远离，难回
用生体：物易得，自会归来
比和：物未失，就在身边
```

### 4.2 实战案例分析

**来源**：[知乎 - 梅花易数初体验，算一算什么东西被拿走了](https://zhuanlan.zhihu.com/p/589830065)

#### 射覆游戏案例
**设置**：
- 准备4个物品：红色水壶、黑色袜子、一本书、一把钳子
- 让人拿走一个后起卦

**起卦**：得革卦（离上兑下）

**分析过程**：
1. 上卦离 → 红色、中空、器皿
2. 下卦兑 → 缺口、开合
3. 综合判断 → **红色水壶**（有盖可开合，符合兑卦）

**结果**：正确！

**关键启示**：
- 需要综合上下卦的象征
- 不能只看单一特征
- 生活常识很重要

## 五、外应理论

### 5.1 什么是外应

**来源**：[知乎 - 学会梅花易，行事不犹豫](https://www.thepaper.cn/newsDetail_forward_18131387)

> 梅花易数大量用到"外应"。占卜过程中，周围环境的任何变化都可能是天意的显现。

#### 外应的类型
1. **自然现象**：
   - 鸟飞（震卦 - 动）
   - 风起（巽卦 - 风）
   - 雨落（坎卦 - 水）
   - 雷鸣（震卦 - 雷）

2. **人为现象**：
   - 敲门声（数声音起卦）
   - 说话内容（字占）
   - 突然看到的物品

3. **时间巧合**：
   - 起卦时刻的时辰
   - 遇到事件的年月日

---

### 5.2 外应与卦象的结合

**经典案例**：康节观梅

**来源**：[百度百科 - 梅花易数](https://baike.baidu.com/item/梅花易数/779052)

**事件**：
> 某辰年十二月十七日申时，康节先生在花园赏梅花，看到两只麻雀争枝坠地

**起卦**：
- 年月日时起卦得泽火革
- 动爻在六爻

**外应**：
- 两只麻雀 → 兑卦（二数，两只；兑为鸟）
- 坠地 → 地、离卦（火下坠）

**断卦**：
> 明晚会有女子来折梅花，园丁不知而逐之，女子惊吓坠地伤膝

**结果**：第二天晚上果然如此！

**关键**：
- 麻雀坠地 → 女子坠地（类象转换）
- 兑为少女 → 年轻女子
- 离为腿 → 伤膝盖

## 八、常见问题 FAQ

### Q1: 为什么同样的问题，不同时间起卦结果不同？
**A**: 这是正常的。梅花易数讲究"机动灵活"，不同时间、不同心境、不同环境，卦象自然不同。关键是当下这一卦的启示。

### Q2: 算出来的结果不准怎么办？
**A**:
1. 检查起卦方式是否正确
2. 检查断卦时是否考虑了体用、互卦
3. 是否忽略了外应
4. 算法只是工具，解读需要经验

### Q3: 可以对同一件事反复起卦吗？
**A**: 古人认为"一事不二卜"。如果已经起过卦，就应该按卦象行事，而不是反复起卦直到得到满意答案。

### Q4: 梅花易数和六爻有什么区别？
**A**:
- 梅花易数：灵活、快速、依靠外应和体用
- 六爻：严谨、复杂、依靠六亲、世应、动爻
