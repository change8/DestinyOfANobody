# 06 | 核心数据对象说明

## 文档说明

本文档详细说明 Fortune Engine 项目中的所有核心数据对象、接口定义和类型系统。

## 一、八字（BaZi）模块数据对象

### 1.1 基础类型

#### Tiangan（天干）
```typescript
type Tiangan = '甲' | '乙' | '丙' | '丁' | '戊' | '己' | '庚' | '辛' | '壬' | '癸';
```
**说明**：十天干，代表阳性的时间能量

#### Dizhi（地支）
```typescript
type Dizhi = '子' | '丑' | '寅' | '卯' | '辰' | '巳' | '午' | '未' | '申' | '酉' | '戌' | '亥';
```
**说明**：十二地支，代表阴性的时间能量

#### Wuxing（五行）
```typescript
type Wuxing = '木' | '火' | '土' | '金' | '水';
```
**说明**：五行元素，描述能量的本质属性

#### YinYang（阴阳）
```typescript
type YinYang = '阴' | '阳';
```

#### ShiShen（十神）
```typescript
type ShiShen =
  | '比肩'  // 同我，代表竞争、兄弟
  | '劫财'  // 阴阳同性，代表竞争、劫夺
  | '食神'  // 我生，阴阳异性，代表表达、才华
  | '伤官'  // 我生，阴阳同性，代表反叛、创新
  | '偏财'  // 我克，阴阳异性，代表意外之财
  | '正财'  // 我克，阴阳同性，代表正常收入
  | '七杀'  // 克我，阴阳异性，代表压力、挑战
  | '正官'  // 克我，阴阳同性，代表正统、权威
  | '偏印'  // 生我，阴阳异性，代表偏门学问
  | '正印'; // 生我，阴阳同性，代表正统教育
```
**说明**：十神是日主与其他天干的关系，用于性格和命运分析

---

### 1.2 核心结构体

#### Pillar（柱）
```typescript
interface Pillar {
  gan: Tiangan;        // 天干
  zhi: Dizhi;          // 地支
  ganIndex: number;    // 天干索引 (0-9)
  zhiIndex: number;    // 地支索引 (0-11)
  jiaziIndex?: number; // 六十甲子索引 (0-59)
}
```
**说明**：一柱代表一个时间单位的干支组合

**示例**：
```json
{
  "gan": "甲",
  "zhi": "子",
  "ganIndex": 0,
  "zhiIndex": 0,
  "jiaziIndex": 0
}
```

#### Pillars（四柱八字）
```typescript
interface Pillars {
  year: Pillar;   // 年柱
  month: Pillar;  // 月柱
  day: Pillar;    // 日柱（日主）
  hour: Pillar;   // 时柱
}
```
**说明**：四柱八字，是命理分析的核心数据

**关键点**：
- 年柱：代表祖上、童年（0-16岁）
- 月柱：代表父母、青年（16-32岁）
- 日柱：代表自己、配偶，是分析的核心
- 时柱：代表子女、晚年（48岁以后）

### 1.3 分析结果对象

#### ShiShenAnalysis（十神分析）
```typescript
interface ShiShenAnalysis {
  year: ShiShen;
  month: ShiShen;
  day: '日主';    // 日柱永远是日主

```

#### NayinAnalysis（纳音分析）
```typescript
interface NayinAnalysis {
  year: string;   // 如："海中金"

  day: string;
  hour: string;
}
```
**说明**：纳音是根据干支组合推算的五行属性，60组干支对应30种纳音

#### CangganAnalysis（藏干分析）
```typescript
interface CangganAnalysis {
  year: Tiangan[];   // 年支中藏的天干
  month: Tiangan[];  // 月支中藏的天干
  day: Tiangan[];
  hour: Tiangan[];
}
```
**说明**：地支中隐藏的天干，用于深度分析五行力量

**示例**：
- 子（水）藏：癸
- 丑（土）藏：己、癸、辛
- 寅（木）藏：甲、丙、戊

#### WuxingAnalysis（五行分析）
```typescript
interface WuxingAnalysis {
  count: WuxingCount;          // 五行个数统计
  strength: WuxingStrength;    // 五行力量百分比
  dayMasterWuxing: Wuxing;     // 日主五行
  dayMasterStrength: '身旺' | '中和' | '身弱';  // 日主强弱
  xiyongshen: string;          // 喜用神（有利的五行）
  jishen: string;              // 忌神（不利的五行）
}

interface WuxingCount {
  木: number;
  火: number;
  土: number;
  金: number;
  水: number;
}

interface WuxingStrength {
  木: number;  // 0-100
  火: number;
  土: number;
  金: number;
  水: number;
}
```
**说明**：五行分析是判断命局强弱、确定喜忌神的关键

### 2.2 起卦结果

#### GuaResult（卦象结果）
```typescript
interface GuaResult {
  // 基本信息
  upperGua: BaGua;        // 上卦（外卦）
  lowerGua: BaGua;        // 下卦（内卦）
  changingLine: number;   // 动爻（1-6）
  mainGuaName: string;    // 主卦名，如"水山蹇"

  // 变卦信息
  changeGua?: {
    upperGua: BaGua;
    lowerGua: BaGua;
    guaName: string;
  };

  // 起卦方法
  method: string;  // 如："数字起卦"、"字占起卦"、"时间起卦"

  // 原始数据
  rawData: {
    upperNumber: number;
    lowerNumber: number;
    totalNumber: number;
    character?: string;  // 如果是字占，记录原始字符
  };

  // 字义分析（仅字占时有）
  charAnalysis?: CharAnalysisResult;
}
```

**关键概念**：
- **上卦（外卦）**：代表外部、他人、事物的外在表现
- **下卦（内卦）**：代表内部、自己、事物的内在本质
- **动爻**：变化的焦点，1-6从下往上数
- **变卦**：动爻变化后形成的新卦，代表事物的发展结果

### 2.3 体用分析

#### TiYongRelation（体用关系）
```typescript
type TiYongRelation =
  | '体克用'   // 我克他，可成但费力
  | '用克体'   // 他克我，凶险难成
  | '体生用'   // 我生他，耗损自己
  | '用生体'   // 他生我，吉利易成
  | '比和';     // 同类，平稳
```

#### TiYongAnalysis（体用分析结果）
```typescript
interface TiYongAnalysis {
  // 体卦信息
  体卦: {
    卦名: BaGua;
    五行: Wuxing;
    卦数: number;
    象征: string;
  };

  // 用卦信息
  用卦: {
    卦名: BaGua;
    五行: Wuxing;
    卦数: number;
    象征: string;
  };

  // 体用关系
  体用关系: TiYongRelation;

  // 生克分析
  生克分析: {
    关系描述: string;
    强弱判断: string;
    吉凶: '大吉' | '吉' | '平' | '凶' | '大凶';
  };

  // 失物占专用判断
  失物判断?: {
    能否找到: boolean;
    难易程度: '很容易' | '容易' | '普通' | '较难' | '很难';
    寻找建议: string;
  };
}
```

**核心理论**：
- **体卦**：无动爻的卦，代表自己、主体、内在
- **用卦**：有动爻的卦，代表外部、事物、他人

**体用确定规则**：
- 动爻在上卦（4、5、6爻）→ 上卦为用卦，下卦为体卦
- 动爻在下卦（1、2、3爻）→ 下卦为用卦，上卦为体卦

### 2.4 互卦分析

#### HuguaResult（互卦结果）
```typescript
interface HuguaResult {
  上互卦: BaGua;     // 由3、4、5爻组成
  下互卦: BaGua;     // 由2、3、4爻组成
  互卦名: string;    // 如："地山谦"

  互卦含义: {
    上互象征: string;
    下互象征: string;
    整体含义: string;
  };
}
```

**说明**：互卦代表事物发展的中间过程

**互卦取法**：
```
六爻卦（从下往上）：初爻、二爻、三爻、四爻、五爻、上爻
下互卦 = 二爻 + 三爻 + 四爻
上互卦 = 三爻 + 四爻 + 五爻
```

**示例**：水山蹇（☵☶）
```
上卦坎（☵）：010
下卦艮（☶）：100
从下往上：1-0-0-0-1-0
下互：2-3-4爻 = 0-0-0 = 坤（☷）
上互：3-4-5爻 = 0-0-1 = 艮（☶）
互卦 = 地山谦
```

### 2.5 字义分析

#### CharStructure（字的结构）
```typescript
type CharStructure =
  | '独体字'    // 如：人、水、火
  | '左右结构'  // 如：找、好、明
  | '上下结构'  // 如：字、家、空
  | '左中右'    // 如：谢、树
  | '上中下'    // 如：意、章
  | '半包围'    // 如：问、同
  | '全包围';   // 如：国、回
```

#### CharAnalysisResult（字义分析结果）
```typescript
interface CharAnalysisResult {
  // 基本信息
  character: string;
  笔画数: number;

  // 结构分析
  结构: CharStructure;
  部首?: string;
  部首信息?: {
    五行: '金' | '木' | '水' | '火' | '土';
    象征: string[];
    相关卦: BaGua[];
  };

  // 语义分析
  语义?: {
    含义: string[];
    象征: string[];
    相关卦: BaGua[];
    五行倾向?: '金' | '木' | '水' | '火' | '土';
  };

  // 综合判断
  建议卦象: BaGua[];
  分析说明: string;
}
```

**分析维度**：
1. **笔画数**：用于数字起卦
2. **部首**：偏旁的五行属性和象征意义
3. **结构**：字形结构暗示的象征
4. **语义**：字的本义、引申义

**示例**：分析"找"字
```json
{

  "结构": "左右结构",
  "部首": "扌",

    "相关卦": ["震"]
  },
  "语义": {
    "含义": ["寻找", "搜索", "追寻"],
    "象征": ["主动", "手部动作", "不安"],
    "相关卦": ["震", "艮"],
```

## 六、数据对象设计原则

### 6.1 类型安全

所有数据对象都使用 TypeScript 严格类型定义：
- 使用 `type` 定义联合类型（如 BaGua、Wuxing）
- 使用 `interface` 定义对象结构
- 使用 `enum` 定义有限枚举（如 BaGuaIndex）

### 6.2 不可变性

核心数据对象应保持不可变：
- 输入对象只读，不在内部修改
- 结果对象完整返回，不依赖副作用
- 使用纯函数处理数据转换

### 6.3 完整性

每个结果对象都包含：
- 原始输入信息（可追溯）
- 中间计算结果（可验证）
- 最终分析结论（可使用）
- 元数据信息（可审计）

### 6.4 可扩展性

预留扩展字段：
- 使用 `?:` 定义可选字段
- 保留 `metadata` 或 `extra` 字段
- 支持自定义分析器
