# Fortune Engine 商业化数据库设计方案

## 说明

本文档为基于 Fortune Engine 开发商业化应用的数据库设计参考方案。

**重要**：Fortune Engine 本身是**纯算法引擎**，不包含数据库和用户系统。本方案用于指导开发者构建商业化应用层。

---

## 一、技术栈建议

### 推荐方案1：Node.js 全栈

```
后端：Node.js + Express/Koa + TypeScript
数据库：PostgreSQL（推荐）/ MySQL
ORM：Prisma / TypeORM
认证：JWT + bcrypt
缓存：Redis
前端：React/Vue + fortune-engine（npm包）
```

### 推荐方案2：Python 后端

```
后端：FastAPI/Django + Python
数据库：PostgreSQL
ORM：SQLAlchemy / Django ORM
认证：JWT + passlib
前端：调用后端API + fortune-engine（通过Node.js微服务）
```

## 二、数据库表设计

### 核心表结构（PostgreSQL DDL）

#### 1. 用户表 (users)

```sql
CREATE TABLE users (
  -- 主键
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),

  -- 登录凭证（支持多种方式）
  username VARCHAR(50) UNIQUE,              -- 用户名登录
  email VARCHAR(255) UNIQUE,                 -- 邮箱登录
  phone VARCHAR(20) UNIQUE,                  -- 手机号登录
  password_hash VARCHAR(255) NOT NULL,       -- 密码哈希（bcrypt）

  -- 用户信息
  nickname VARCHAR(100),                     -- 昵称
  avatar_url VARCHAR(500),                   -- 头像URL
  gender CHAR(1) CHECK (gender IN ('M', 'F', 'U')), -- 性别：M=男, F=女, U=未知
  birthday DATE,                             -- 生日（可选）

  -- 账号状态
  status VARCHAR(20) DEFAULT 'active'        -- active, suspended, deleted
    CHECK (status IN ('active', 'suspended', 'deleted')),
  email_verified BOOLEAN DEFAULT FALSE,      -- 邮箱是否验证
  phone_verified BOOLEAN DEFAULT FALSE,      -- 手机号是否验证

  -- VIP/会员信息
  vip_level INTEGER DEFAULT 0,               -- 0=普通, 1=VIP1, 2=VIP2...
  vip_expire_at TIMESTAMP,                   -- VIP到期时间

  -- 时间戳
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  last_login_at TIMESTAMP,

  -- 索引
  INDEX idx_username (username),
  INDEX idx_email (email),
  INDEX idx_phone (phone),
  INDEX idx_status (status),
  INDEX idx_created_at (created_at)
);
```

#### 2. 八字排盘记录表 (bazi_records)

```sql
CREATE TABLE bazi_records (
  -- 主键
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id) ON DELETE CASCADE,

  -- 排盘输入
  person_name VARCHAR(100),                  -- 人物名称（可选）
  birth_date DATE NOT NULL,                  -- 出生日期
  birth_time TIME NOT NULL,                  -- 出生时间
  birth_timezone INTEGER DEFAULT 8,          -- 时区
  birth_longitude DECIMAL(9, 6),             -- 经度（真太阳时）
  gender CHAR(1) NOT NULL                    -- M=男, F=女
    CHECK (gender IN ('M', 'F')),

  -- 排盘选项
  use_true_solar_time BOOLEAN DEFAULT FALSE, -- 是否使用真太阳时
  zi_shi_method VARCHAR(20) DEFAULT 'traditional', -- 子时处理方式

  -- 完整排盘结果（JSON存储）
  result_json JSONB NOT NULL,                -- Fortune Engine返回的完整BaziResult

  -- 快速查询字段（冗余，便于统计分析）
  year_gan CHAR(1),                          -- 年干
  year_zhi CHAR(1),                          -- 年支
  month_gan CHAR(1),
  month_zhi CHAR(1),
  day_gan CHAR(1),                           -- 日主天干
  day_zhi CHAR(1),
  hour_gan CHAR(1),
  hour_zhi CHAR(1),
  day_master_wuxing VARCHAR(2),              -- 日主五行
  day_master_strength VARCHAR(4),            -- 身旺/中和/身弱

  -- 标签和备注
  tags TEXT[],                               -- 标签数组
  note TEXT,                                 -- 用户备注
  is_favorite BOOLEAN DEFAULT FALSE,         -- 是否收藏

  -- 时间戳
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

  -- 索引
  INDEX idx_user_id (user_id),
  INDEX idx_birth_date (birth_date),
  INDEX idx_day_gan (day_gan),
  INDEX idx_created_at (created_at),
  INDEX idx_is_favorite (is_favorite)
);
```

### 2. 八字排盘 API

#### POST /api/bazi/calculate - 计算八字

```typescript
import { BaziCalculator } from 'fortune-engine';

interface CalculateBaziRequest {
  personName?: string;
  birthDate: string;      // "1990-01-01"
  birthTime: string;      // "08:30"
  gender: 'M' | 'F';
  useTrueSolarTime?: boolean;
  longitude?: number;
  saveRecord?: boolean;   // 是否保存到数据库
}

// 后端处理
async function calculateBazi(req, res) {
  const { userId } = req.user;  // 从JWT获取
  const input = req.body;

  // 1. 使用 Fortune Engine 计算
  const calculator = new BaziCalculator();
  const result = calculator.calculate({
    birthDate: input.birthDate,
    birthTime: input.birthTime,
    gender: input.gender === 'M' ? 'male' : 'female',
    options: {
      useTrueSolarTime: input.useTrueSolarTime,
      longitude: input.longitude
    }
  });

  // 2. 保存到数据库（如果需要）
  if (input.saveRecord) {
    await prisma.baziRecord.create({
      data: {
        userId,
        personName: input.personName,
        birthDate: new Date(input.birthDate),
        birthTime: new Date(`${input.birthDate} ${input.birthTime}`),
        gender: input.gender,
        useTrueSolarTime: input.useTrueSolarTime || false,
        resultJson: result,  // 存储完整结果
        // 提取关键字段便于查询
        yearGan: result.pillars.year.gan,
        yearZhi: result.pillars.year.zhi,
        dayGan: result.pillars.day.gan,
        dayMasterWuxing: result.wuxing.dayMasterWuxing,
        dayMasterStrength: result.wuxing.dayMasterStrength
      }
    });
  }

  // 3. 返回结果
  res.json({
    success: true,
    data: result
  });
}
```

```typescript
async function getBaziRecords(req, res) {
```

### 3. 梅花易数 API

#### POST /api/meihua/qigua - 起卦

```typescript
import { qiguaByChar, qiguaByTone, divineForLostItem } from 'fortune-engine';

interface QiguaRequest {
  method: 'char' | 'tone' | 'structure' | 'direction' | 'environment';
  input: any;  // 根据method不同而不同
  question: string;
  category?: string;  // 失物、感情、事业等
  saveRecord?: boolean;
}

async function qigua(req, res) {
  const { userId } = req.user;
  const { method, input, question, category, saveRecord } = req.body;

  // 1. 根据方法起卦
  let guaResult;
  switch (method) {
    case 'char':
      guaResult = qiguaByChar(input.char, input.strokeCount);
      break;
    case 'tone':
      guaResult = qiguaByTone(input.chars, input.tones);
      break;
    // ... 其他方法
  }

  // 2. 断卦（如果是失物占）
  let divinationResult;
  if (category === '失物') {
    divinationResult = divineForLostItem(guaResult, question, input.itemName);
  }

  // 3. 保存记录
  if (saveRecord) {
    await prisma.meihuaRecord.create({
      data: {
        userId,
        question,
        questionCategory: category,
        qiguaMethod: method,
        qiguaInput: input,
        mainGuaName: guaResult.mainGuaName,
        upperGua: guaResult.upperGua,
        lowerGua: guaResult.lowerGua,
        changingLine: guaResult.changingLine,
        guaResultJson: guaResult,
        divinationResultJson: divinationResult
      }
    });
  }

  // 4. 返回结果
  res.json({
    success: true,
    data: {
      guaResult,
      divinationResult
    }
  });
}
```

## 六、安全建议

### 1. 密码安全

```typescript
import bcrypt from 'bcrypt';

// 注册时加密密码
const saltRounds = 10;
const passwordHash = await bcrypt.hash(password, saltRounds);

// 登录时验证密码
const isValid = await bcrypt.compare(password, user.passwordHash);
```

### 2. JWT 认证

```typescript
import jwt from 'jsonwebtoken';

// 生成 token
const token = jwt.sign(
  { userId: user.id, username: user.username },
  process.env.JWT_SECRET,
  { expiresIn: process.env.JWT_EXPIRE_TIME }
);

// 验证 token（中间件）
function authMiddleware(req, res, next) {
  const token = req.headers.authorization?.replace('Bearer ', '');

  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.user = decoded;
    next();
  } catch (err) {
    res.status(401).json({ error: '未授权' });
  }
}
```

## 八、部署建议

### 开发环境

```bash
# 1. 启动数据库（Docker）
docker run -d --name fortune-db \
  -e POSTGRES_PASSWORD=password \
  -p 5432:5432 postgres:14

# 2. 运行数据库迁移
npx prisma migrate dev

# 3. 启动后端
npm run dev

# 4. 启动前端
cd frontend && npm run dev
```

### 生产环境

```bash
# 使用 Docker Compose
version: '3.8'
services:
  db:
    image: postgres:14
    environment:
      POSTGRES_DB: fortune_db
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    volumes:
      - pgdata:/var/lib/postgresql/data

  redis:
    image: redis:7-alpine

  backend:
    build: ./backend
    ports:
      - "3000:3000"
    depends_on:
      - db
      - redis
    environment:
      DATABASE_URL: postgresql://postgres:${DB_PASSWORD}@db:5432/fortune_db
      REDIS_URL: redis://redis:6379

  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf
      - ./ssl:/etc/nginx/ssl

  pgdata:
```

## 九、总结

### Fortune Engine 的角色

- ✅ **纯计算引擎**：无状态、无数据库、纯算法
- ✅ **npm包形式**：后端通过 `import` 使用
- ✅ **不关心用户系统**：只负责算法计算

### 商业化应用的职责

- ✅ 用户注册、登录、权限管理
- ✅ 数据存储（占卜记录、浏览历史）
- ✅ 支付系统（VIP、次数购买）
- ✅ API服务（封装Fortune Engine）
- ✅ 前端界面

### 关键设计原则

1. **分层架构**：应用层 ↔ 算法引擎层分离
2. **数据隐私**：用户数据加密、HTTPS传输
3. **可扩展性**：Redis缓存、数据库主从
4. **性能优化**：限流、分页、索引优化
