## 一、八字排盘业务规则

### 1.1 时间范围约束

#### 数据支持范围
- **最小日期**：1900年1月1日
- **最大日期**：2100年12月31日
- **原因**：农历数据和节气数据的预置范围

**实现规则**：
```typescript
function validateDateRange(date: Date): void {
  const MIN_YEAR = 1900;
  const MAX_YEAR = 2100;

  if (date.getFullYear() < MIN_YEAR || date.getFullYear() > MAX_YEAR) {
    throw new OutOfRangeError(
      `日期必须在 ${MIN_YEAR}-${MAX_YEAR} 年之间`
    );
  }
}
```

### 1.2 年柱起算规则

#### 立春换年
- **规则**：年柱以**立春**为界，不是以农历正月初一
- **原因**：八字命理遵循节气历（太阳历），不是阴历

**示例**：
```
2020年立春时间：2020年2月4日 17:03

- 2020年2月4日 17:02 出生 → 年柱为 己亥年（2019年）
- 2020年2月4日 17:04 出生 → 年柱为 庚子年（2020年）
```

**实现规则**：
```typescript
function calculateYearPillar(birthDate: Date, lichunTime: Date): Pillar {
  // 出生时间在立春之前，使用上一年的干支
  if (birthDate < lichunTime) {
    return getPreviousYearGanZhi(birthDate.getFullYear());
  }
  return getCurrentYearGanZhi(birthDate.getFullYear());
}
```

### 1.3 月柱起算规则

#### 节气换月
- **规则**：月柱以**节**（节气）为界，不是农历每月初一
- **12个节气对应12个月**：
  - 正月：立春（寅月）
  - 二月：惊蛰（卯月）
  - 三月：清明（辰月）
  - 四月：立夏（巳月）
  - 五月：芒种（午月）
  - 六月：小暑（未月）
  - 七月：立秋（申月）
  - 八月：白露（酉月）
  - 九月：寒露（戌月）
  - 十月：立冬（亥月）
  - 十一月：大雪（子月）
  - 十二月：小寒（丑月）

**月柱起法**（五虎遁月）：
```
年干      正月（寅）  二月（卯）  三月（辰）...
甲、己    丙寅        丁卯        戊辰
乙、庚    戊寅        己卯        庚辰
丙、辛    庚寅        辛卯        壬辰
丁、壬    壬寅        癸卯        甲辰
戊、癸    甲寅        乙卯        丙辰
```

### 1.4 日柱起算规则

#### 万年历查表法
- **规则**：日柱以**子正**（23:00）为界
- **计算方法**：使用六十甲子推算公式
- **关键点**：日柱计算最为复杂，需要考虑闰年、大小月

**实现规则**：
```typescript
function calculateDayPillar(date: Date): Pillar {
  // 基准日：1900年1月1日 = 甲戌日
  const BASE_DATE = new Date(1900, 0, 1);
  const BASE_JIAZI_INDEX = 10; // 甲戌

  // 计算天数差
  const daysDiff = getDaysDifference(BASE_DATE, date);

  // 六十甲子循环
  const jiaziIndex = (BASE_JIAZI_INDEX + daysDiff) % 60;

  return SIXTY_JIAZI[jiaziIndex];
}
```

### 1.5 时柱起算规则

#### 子时处理（关键争议点）

**传统方法**（`ziShiMethod: 'traditional'`）：
- **早子时**（23:00 - 00:00）：算前一天，时柱为甲子时
- **晚子时**（00:00 - 01:00）：算当天，时柱为丙子时

**现代方法**（`ziShiMethod: 'modern'`）：

**项目默认**：使用传统方法

### 1.6 真太阳时修正规则

#### 什么是真太阳时？

中国标准时间基于东经120度，但各地实际经度不同，导致**地方时**与**标准时**有偏差。

**修正公式**：
```
真太阳时 = 标准时 + (当地经度 - 120) × 4分钟
```

**示例**：
- 北京（东经116.4度）：真太阳时 = 标准时 - 14.4分钟
- 乌鲁木齐（东经87.6度）：真太阳时 = 标准时 - 129.6分钟

**实现规则**：
```typescript
function applyTrueSolarTime(
  standardTime: Date,
  longitude: number
): Date {
  // 计算时差（分钟）
  const timeDiff = (longitude - 120) * 4;

  // 修正时间
  return new Date(standardTime.getTime() + timeDiff * 60 * 1000);
}
```

**使用建议**：
- 专业排盘：**建议开启**
- 普通用户：可选

### 1.7 十神计算规则

#### 定义
十神是日主天干与其他天干的生克关系。

#### 计算规则
1. 以**日干**为"我"
2. 判断其他干支与日干的五行关系
3. 结合阴阳同性/异性确定具体十神

**五行关系表**：
```
日干   其他干    关系      阴阳同性    阴阳异性
甲     甲、乙    比和      比肩        劫财
甲     丙、丁    我生      食神        伤官
甲     戊、己    我克      偏财        正财
甲     庚、辛    克我      七杀        正官
甲     壬、癸    生我      偏印        正印
```

**实现规则**：
```typescript
function calculateShiShen(dayGan: Tiangan, otherGan: Tiangan): ShiShen {
  if (dayGan === otherGan) return '比肩';

  const dayWuxing = GAN_WUXING[dayGan];
  const otherWuxing = GAN_WUXING[otherGan];
  const sameYinYang = isSameYinYang(dayGan, otherGan);

  const relation = getWuxingRelation(dayWuxing, otherWuxing);

  if (relation === '生') return sameYinYang ? '食神' : '伤官';
  if (relation === '克') return sameYinYang ? '偏财' : '正财';
  if (relation === '被克') return sameYinYang ? '七杀' : '正官';
  if (relation === '被生') return sameYinYang ? '偏印' : '正印';
  if (relation === '比和') return sameYinYang ? '比肩' : '劫财';
}
```

### 1.8 五行强弱判断规则

#### 计算方法

1. **天干得分**：
   - 年干：10分
   - 月干：30分
   - 日干：20分
   - 时干：10分

2. **地支得分**：
   - 年支：10分
   - 月支：30分（月令最重要）
   - 日支：20分
   - 时支：10分

3. **藏干得分**：
   - 本气（主气）：100%
   - 中气：70%
   - 余气：50%

#### 判断标准

**日主强弱**：
- **身旺**：日主五行得分 > 50%
- **中和**：日主五行得分 40% - 60%
- **身弱**：日主五行得分 < 40%

**喜用神确定**：
- 身旺：需要**克、泄、耗**，喜用神为克我、我生、我克的五行
- 身弱：需要**生、帮**，喜用神为生我、与我同类的五行

## 二、梅花易数业务规则

### 2.1 起卦规则

#### 2.1.1 数字起卦

**规则**：
- 上卦数 ÷ 8 取余数（余数为0则取8）
- 下卦数 ÷ 8 取余数（余数为0则取8）
- 总数 ÷ 6 取余数（余数为0则取6）→ 动爻位置

**数字对应八卦**：
```
1 - 乾 ☰
2 - 兑 ☱
3 - 离 ☲
4 - 震 ☳
5 - 巽 ☴
6 - 坎 ☵
7 - 艮 ☶
8 - 坤 ☷
```

**实现规则**：
```typescript
function getGuaByNumber(num: number): BaGua {
  const absNum = Math.abs(num);
  const index = ((absNum - 1) % 8) + 1;  // 确保1-8范围
  return BA_GUA_BY_INDEX[index];
}

function getChangingLine(num: number): number {
  const line = ((num - 1) % 6) + 1;  // 确保1-6范围
  return line;
}
```

---

#### 2.1.2 字占起卦

**基本规则**（传统）：
- 字的笔画数 → 上卦数
- 字的笔画数 → 下卦数
- 笔画数 × 2 → 总数（动爻）

**增强规则**（本项目）：
除了笔画数，还需分析：
1. **字的语义**：含义、象征
2. **字的部首**：五行属性
3. **字的结构**：独体、左右、上下等
4. **字的声调**：平仄

**笔画数规则**：
- 使用**康熙字典笔画**，不是简化字笔画
- 特殊部首的笔画数：
  - "氵" = 4画（水）
  - "扌" = 4画（手）
  - "忄" = 4画（心）
  - "犭" = 4画（犬）
  - "艹" = 6画（草）
  - "辶" = 7画（走）

---

#### 2.1.3 时间起卦

**规则**：
```
上卦数 = (年数 + 月数 + 日数) % 8
下卦数 = (年数 + 月数 + 日数 + 时辰数) % 8
动爻数 = (年数 + 月数 + 日数 + 时辰数) % 6
```

**时辰对应数字**：
```
子时(23-01) = 1
丑时(01-03) = 2
寅时(03-05) = 3
卯时(05-07) = 4
辰时(07-09) = 5
巳时(09-11) = 6
午时(11-13) = 7
未时(13-15) = 8
申时(15-17) = 9
酉时(17-19) = 10
戌时(19-21) = 11
亥时(21-23) = 12
```

### 2.2 体用确定规则

**核心规则**：
- 动爻在上卦（4、5、6爻）→ **上卦为用卦，下卦为体卦**
- 动爻在下卦（1、2、3爻）→ **下卦为用卦，上卦为体卦**

**理论依据**：
- **体卦**：无动爻，代表自己、主体、内在、静态
- **用卦**：有动爻，代表外部、事物、他人、动态

**实现规则**：
```typescript
function determineTiYong(guaResult: GuaResult): {
  体卦: BaGua;
  用卦: BaGua;
} {
  const { upperGua, lowerGua, changingLine } = guaResult;

  if (changingLine >= 4) {
    return { 体卦: lowerGua, 用卦: upperGua };
  } else {
    return { 体卦: upperGua, 用卦: lowerGua };
  }
}
```

### 2.3 五行生克规则

#### 相生关系
```
木 → 火 → 土 → 金 → 水 → 木（循环）
```

#### 相克关系
```
木 → 土 → 水 → 火 → 金 → 木（循环）
```

#### 体用生克吉凶

**五种关系及其判断**：

| 关系 | 说明 | 失物占判断 | 吉凶 |
|------|------|-----------|------|
| **用生体** | 外部生助我 | 物易寻，就在附近 | 大吉 |
| **比和** | 同类相助 | 物未失，仔细找 | 吉 |
| **体克用** | 我能克制外部 | 可找到，需努力 | 吉 |
| **体生用** | 我耗损给外部 | 物难见，已远离 | 平 |
| **用克体** | 外部克制我 | 难以找到 | 凶 |

**实现规则**：
```typescript
function getWuxingRelation(from: Wuxing, to: Wuxing):
  '生' | '克' | '被生' | '被克' | '比和' {

  const sheng: Record<Wuxing, Wuxing> = {
    '木': '火', '火': '土', '土': '金', '金': '水', '水': '木'
  };

  const ke: Record<Wuxing, Wuxing> = {
    '木': '土', '土': '水', '水': '火', '火': '金', '金': '木'
  };

  if (from === to) return '比和';
  if (sheng[from] === to) return '生';
  if (sheng[to] === from) return '被生';
  if (ke[from] === to) return '克';
  if (ke[to] === from) return '被克';

  return '比和';
}
```

### 2.5 八卦类象规则

#### 类象分类

每个八卦有多个维度的类象：

1. **五行属性**：金、木、水、火、土
2. **阴阳属性**：阳、阴
3. **方位**：八方位
4. **物象**：形状、颜色、质地、物品
5. **人物**：家庭成员、社会角色
6. **身体部位**：对应人体器官
7. **时间特征**：快慢、远近
8. **数字**：对应的数字

#### 应用规则

**失物占**：
- **方位**：根据体卦和用卦的方位确定
- **位置高低**：根据卦的象征（乾为天→高，坤为地→低）
- **物品特征**：根据物象（形状、颜色、材质）
- **距离远近**：根据时间特征

**示例**：乾卦类象

### 2.6 交互式断卦规则

#### 阶段划分

断卦过程分为6个阶段：
1. **initial**：初步起卦
2. **direction**：确定方位
3. **location**：确定具体位置
4. **features**：确定物品特征
5. **timing**：确定时间
6. **final**：最终结论

#### 置信度调整规则

**初始置信度**：
- 用生体：90%
- 比和：70%
- 体克用：60%
- 体生用：40%
- 用克体：20%

**调整规则**：
- 用户确认正确：+10%
- 用户否认：-20%
- 用户部分正确：+5%
- 再起一数/字：重新计算

**外应规则**：
- 突发事件（敲门、电话）：记录并分析
- 看到特殊物品：结合卦象分析
- 听到声音：震卦、兑卦相关

- 不使用简单的查表法

- 覆盖200年 × 24节气 = 4800个数据点

## 七、安全性规则

### 7.1 输入安全

**防止注入攻击**：
- 所有输入都经过类型校验
- 不使用 `eval()` 或动态代码执行
- 限制字符串长度

**示例**：
```typescript
function sanitizeInput(input: string): string {
  // 限制长度
  if (input.length > 100) {
    throw new Error('输入过长');
  }

  // 移除危险字符
  return input.replace(/[<>\"']/g, '');
}
```

### 7.2 数据隐私

- 姓名字段可选，仅用于本地展示

## 八、错误处理规则

### 8.1 错误分类

1. **输入错误**（400类）：
   - `InvalidDateError`：无效日期
   - `InvalidTimeError`：无效时间
   - `OutOfRangeError`：超出范围

2. **系统错误**（500类）：
   - `BaziError`：通用错误
   - `CalculationError`：计算错误
